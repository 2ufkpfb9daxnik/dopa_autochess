# 戦闘について

キャラクターは以下の行動をする:

- 攻撃
- バフ/デバフのどちらか一種
- ガード

戦闘はどちらかのキャラクターが全員体力が0以下になった状態のときに終了する。

キャラクターには行動ポイントと呼ばれる値を持つ。これは戦闘中に動的に変化するものである。デフォルトでの行動ポイントは、65535を速度で割った値。

前衛にいるキャラクターのうち、行動ポイントが小さい順に行動する。最も行動ポイントが小さいキャラクターが行動したら、そのキャラクターが持っていた行動ポイントが全員の行動ポイントが引かれる。すると次に行動ポイントが小さいキャラクターが出現するので、次も同じように行動キャラクターは選ばれていく。なお、次の行動キャラクターが選ばれた段階で、はじめに行動したキャラクターももう一度行動の待機列に並ぶ。その時の行動ポイントは減らされておらず、初期化されている。

行動ポイントは戦闘中随時変更されることがある。例えば、キャラクターの速度が上昇することもあれば減少することもある。行動ポイントが直接増えたり減ったりすることもある。味方を即時行動させるときは、この行動ポイントをいきなり0にすることに相当する。

サークルが回転することによって、これまで存在しなかったキャラクターが新たに行動列に入ることがあるが、これも同様に初期化された状態である。ただし、これは初回のみで、次の出現からは、保存された行動ポイントが適用される。

キャラクターが行動するとき、攻撃、バフ/デバフ、ガードのどれをするかは、そのキャラクターの行動割合で1回決める。行動割合は、合計が10になる0以上の整数である。それぞれの行動になる確率は、その整数を10で割った値である。0の行動は選ばれない。

行動のうち、敵のターゲットを選ぶ必要があるときは、ターゲット優先度が高い順に攻撃される。ただし確率であるので、たまーに外れて別のキャラクターを攻撃することもある。これはターゲット中で、ターゲット優先度の差が大きければ大きいほど確率が低くなる。

攻撃は命中することもあれば外れることもある。この確率は攻撃を受ける側の速度に依存する。

## ダメージ

攻撃が命中し、受ける側のガードで防がれなかったとき、攻撃側は次の式でダメージを与える。命中しなかったとき、またはガードで防いだときは、ダメージを 0 にする。

画面上の +20% は、式では 0.2 として入れる。空欄は 0。同じ名前の割合が複数あるときは、式に入れる前に足す。名前が違う割合は足さず、それぞれの係数として掛ける。

式に入れる値は、その攻撃の計算をする時点の値を使う。レリック、シナジー、バフ、デバフは、攻撃力、防御力、貫通率、与ダメージ、属性ダメージ倍率、属性ダメージ耐性、属性耐性、被ダメージ増加、クリティカル率、クリティカルダメージ、継続の割合を、それぞれの効果に書かれたとおりに変える。変えたあとの値を式に入れる。

バフまたはデバフに効果値の表があるとき、使う値は、その効果を出しているキャラクターの星の欄である。欄が空欄の★2以降は、その行の星倍率を★1に掛ける。星倍率の設定が無い行は、★1を1、★2を1.2、★3を1.5、★4を1.7として掛ける。欄に値がある星は、その値を使う。

```text
ダメージ = 攻撃力
         × 防御係数
         × 与ダメージ係数
         × 属性ダメージ係数
         × 属性耐性係数
         × 被ダメージ係数
         × 会心係数
```

攻撃力は、ダメージを計算する時点の、攻撃するキャラクターの攻撃力。バフやデバフで変わっていれば、変わったあとの値を使う。

### 防御係数

受けるキャラクターの防御力で、ダメージを何倍にするかを決める。

```text
防御係数 = 1000 / (1000 + 防御力 × (1 - 貫通率))
```

防御力は、ダメージを計算する時点の、受けるキャラクターの防御力。

貫通率は、攻撃するキャラクターが無視する防御力の割合。貫通 30% は 0.3。貫通がなければ 0。複数あるときは足す。合計が 1 を超えたときは 1 として計算する。そのため防御係数は、防御力 0 のときの 1 を超えない。

防御力 1000、貫通率 0 のとき、防御係数は 1000 / (1000 + 1000) = 0.5。攻撃力 100 で他の係数がすべて 1 なら、ダメージは 50。

防御力 1000、貫通率 0.3 のとき、防御係数は 1000 / (1000 + 1000 × 0.7) = 0.588。同じ条件のダメージは 58.8。

防御力 250、貫通率 0 のとき、防御係数は 0.8。貫通率 0.3 のときは 0.851。

### 与ダメージ係数

攻撃するキャラクターの、属性を指定しない与ダメージの合計。

```text
与ダメージ係数 = 1 + 与ダメージ
```

与ダメージ +20% と与ダメージ +30% は、与ダメージ 0.5 になり、係数は 1.5。属性ダメージ倍率はここには足さない。

### 属性ダメージ係数

攻撃するキャラクターの、今回の攻撃の属性のダメージ倍率。

```text
属性ダメージ係数 = 1 + 属性ダメージ倍率
```

属性ダメージ倍率は、攻撃するキャラクターの属性補正のうち、今回の攻撃の属性の「ダメージ倍率」。炎で攻撃するなら炎の欄を使う。

### 属性耐性係数

受けるキャラクターが、今回の攻撃の属性をどれだけ軽減するか。

```text
属性耐性係数 = 1 - (属性ダメージ耐性 + 属性耐性)
```

属性ダメージ耐性は、受けるキャラクターの属性補正のうち、今回の攻撃の属性の「ダメージ耐性」。

属性耐性は、受けるキャラクターのステータス「属性耐性」。どの属性の攻撃にも、この値を足す。属性耐性 6 は 0.06。マイナスなら属性耐性係数は 1 より大きくなり、ダメージが増える。

### 被ダメージ係数

受けるキャラクターに付いている、受けるダメージの増加。

```text
被ダメージ係数 = 1 + 被ダメージ増加
```

被ダメージ増加は、防御係数を計算したあとに掛ける。防御力の高いキャラクターにも低いキャラクターにも、同じ割合を掛ける。貫通率と違い、この係数が 1 より大きいと、防御力 0 のときより大きいダメージになる。

### 会心係数

攻撃するキャラクターのクリティカル率で、その攻撃がクリティカルするかを決める。クリティカルしなかったときと、したときで係数が変わる。

```text
クリティカルしないとき  会心係数 = 1
クリティカルしたとき    会心係数 = 1 + クリティカルダメージ
```

クリティカルダメージは、攻撃するキャラクターのクリティカルダメージ。+100% は 1 なので、クリティカルした攻撃は、しなかったときの 2 倍になる。

速度は、防御係数にも他の係数にも入れない。速度は行動ポイントの計算に使う。

## 撃破

撃破ゲージを減らせるのは、その属性の「撃破できるようになる」シナジーに入っているキャラクターが、その属性で攻撃したときだけである。他の属性の攻撃では、そのゲージは減らない。そのシナジーに入っていないキャラクターの攻撃でも減らない。

ゲージが 0 になったとき、撃破が起きる。撃破時の効果は、ダメージのときと、ダメージでないときがある。効果の内容は、シナジーやキャラクターごとに別に決める。効果がダメージのときは、その効果に書かれた攻撃力を、通常のダメージの式に入れて計算する。

## 範囲ダメージ

範囲ダメージは、通常の攻撃とは別に、今回の攻撃の属性で与える。攻撃するキャラクターが、その属性の範囲シナジーに入っているときだけ与える。1 体ごとのダメージは、通常のダメージの式で計算する。範囲用の割合は掛けない。

対象は通常の攻撃の対象を含む。体数は、そのシナジーに出ている人数で決まる。2 人のときは 2 体。4 人のときは 2 体。6 人のときは 3 体。人数の設定がないときは、それより少ない人数のうち、最も近い設定を使う。

## 継続ダメージ

継続ダメージは層で与える。炎、水、雷、土、氷、風、吸収は、それぞれ別の層である。その属性の継続シナジーに入っているキャラクターが、その属性で攻撃したあと、攻撃の対象にその属性の継続ダメージを1層与える。命中しなくても、ガードで通常の攻撃のダメージが0になっても、1層与える。戦闘開始時の層は0である。

継続ダメージを1層与えたあとの攻撃力は、与えたあとの、その属性の層数を使って計算する。

```text
継続ダメージの攻撃力 = 攻撃したキャラクターの攻撃力 × 継続の割合 × 層数
```

この攻撃力を、通常のダメージの式の攻撃力に入れる。会心係数は 1 にする。与えたあとが1層のとき、層数を掛ける前の攻撃力と同じになる。

継続の割合は、そのシナジーに出ている人数で決まる。2 人のときは 0.05。4 人のときは 0.10。6 人のときは 0.15。人数の設定がないときは、それより少ない人数のうち、最も近い設定を使う。1人のときは 0.05 を使う。レリックなどの効果があるときは、その効果を適用したあとの割合を式に入れる。

層を持つキャラクターから行動ポイントが引かれると、属性ごとに、引かれた行動ポイントを貯める。貯めた値が、そのキャラクターの戦闘開始時の行動ポイントに達するたびに、その属性の層を1つ消し、達した分を貯めた値から引く。一度の減算で戦闘開始時の行動ポイントに2回到達したときは、層を2つ消す。戦闘開始時の行動ポイントは、65535を戦闘開始時の速度で割った値である。速度100なら655になる。層が0の属性は、行動ポイントを貯めない。

キャラクターの説明が、継続ダメージを2層以上与えると書いているときは、書いた層数を足してから、上の式で攻撃力を計算する。説明が攻撃力の掛け方を層数とは別に書いているときだけ、その掛け方を使い、層は足さない。
