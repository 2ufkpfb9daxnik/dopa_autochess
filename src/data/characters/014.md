# イバラキ

- ID: 014
- 名前: イバラキ
- コスト: 2
- シナジー: わたしのグランパ, スウィング, 東雲
- 攻撃属性: 水
- 得意属性3つ: 吸収, 土, 炎
- 苦手属性3つ: 氷, 風, 雷

## 簡単な説明文

攻撃されると、最大体力が上がる。

## 詳細な説明文

敵が対象を選ぶ行動では、イバラキのターゲット優先度として、各種ステータスの表の値を使う。この値が高いほど、イバラキが選ばれやすい。イバラキ以外の味方が選ばれる確率は、イバラキとその味方のターゲット優先度の差が大きいほど低くなる。ターゲット優先度の星倍率は★1から★4まで1なので、★2以降が空欄のときは★1の値153を使う。

イバラキの体力が0より大きいとき、敵の攻撃がイバラキに命中し、イバラキのガードでその攻撃のダメージが0にならなかったら、そのダメージの前に最大体力が上昇する。現在の体力も同じだけ高くなる。上昇は、効果値の被弾時の最大体力の欄にある、イバラキの星の値である。★1は10、★2は12、★3は15、★4は17である。この欄は%ではない。攻撃が来るたびに上昇する。外れと、ガードでダメージが0になった攻撃では上昇しない。範囲ダメージの端にイバラキが含まれるときでも、その攻撃の狙った相手がイバラキでなければ上昇しない。上昇したあとでも体力が0以下になるなら、イバラキは倒れる。

★1で、最大体力29、ほかの上昇がないとき、1回目の前は最大体力39、現在の体力も39になる。この状態で、攻撃力100、防御力257、ほかの上昇がない攻撃のダメージは80である。39では倒れる。

イバラキの体力が0より大きいとき、イバラキの水の攻撃で水の撃破ゲージが0になったら、その戦闘で1回だけ、イバラキが受けるダメージが低くなる。低くなる割合は、効果値の受けるダメージの欄にある、イバラキの星の値である。★1は10%、★2は12%、★3は15%、★4は17%である。この低下は戦闘が終わるまで残る。同じ攻撃でゲージを0にしても、2回目以降はこれ以上低くならない。ゲージを減らしても0にしなかったときは、この低下は起きない。

その1回で、イバラキの属性耐性も上昇し、戦闘が終わるまで残る。どの属性の攻撃にも入る。上昇は、効果値の属性耐性の欄にある、イバラキの星の値である。★1は10%、★2は12%、★3は15%、★4は17%である。各種ステータスの属性耐性と、この上昇をあわせた値が、イバラキの属性耐性である。★1の表の値は7%なので、この上昇の直後は17%になる。

その戦闘で最初にイバラキを対象にした攻撃は、クリティカルしない。攻撃した側のクリティカル率は関係しない。命中しても、外れても、ガードでもクリティカルしない。その攻撃に範囲の端があるとき、端の味方もその攻撃ではクリティカルしない。範囲の端にイバラキがいるだけで、狙った相手がイバラキでなければ、その攻撃は通常どおりクリティカルする。

この最初の攻撃のあと、次にイバラキが受ける命中判定の1回だけ、速度が高いものとして扱われ、攻撃は外れやすくなる。高くなる量は、効果値の命中時の速度の欄にある、イバラキの星の値である。★1は20、★2は24、★3は30、★4は34である。この欄は%ではない。★1の速度112なら、その1回は132として扱う。行動の間隔は変わらない。この1回のあと、速度はもとの扱いに戻る。

イバラキにレリックを装備したとき、数える装備が上限より少なければ、防御力が高くなる。高くなる量は、効果値のスウィングの防御力の欄にある、装備した時点のイバラキの星の値である。★1は10、★2は12、★3は15、★4は17である。この欄は%ではない。スウィングの人数で、この量はさらに高くなる。3人のときは20%高い。5人のときは40%高い。7人のときは60%高い。9人のときは80%高い。その人数と同じ設定がないときは、その人数より少ない設定のうち最も近い設定を使う。3人より少ないときは、欄の値のままである。高くする割合は、装備した時点の人数で決まる。あとから人数が変わっても、すでに高くなった分は変わらない。整数にならないときは、半分以上の端数を切り上げる。数える上限は、効果値のスウィングの装備の欄にある、その時点の星の値である。★1は1、★2は1、★3は2、★4は2である。この欄は%ではない。装備できないレリックは数えず、上限も使わない。すでに装備しているだけでは高くならない。レリックを外しても、この上昇は残る。星が上がっても、すでに高くなった分は変わらない。上限は、その時点の星の値まで増える。

## バフ/デバフ

デバフ。直前にイバラキが攻撃した敵の体力が0より大きいときは、その1体の水のダメージ耐性が低下する。その敵がいないときは、体力が0より大きい敵のうち、ターゲット優先度が最も高い1体を対象にする。低下は、効果値の水のダメージ耐性の欄にある、イバラキの星の値である。★1は10%、★2は12%、★3は15%、★4は17%である。同時に1体だけで、別の敵へデバフしたとき、または対象かイバラキの体力が0以下になったときに消える。
