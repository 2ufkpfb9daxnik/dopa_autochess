# ヨシノ

- ID: 093
- 名前: ヨシノ
- コスト: 2
- シナジー: ポプリ, 新しい下駄を履く, ビストロン
- 攻撃属性: 風
- 得意属性3つ: 氷, 雷, 水
- 苦手属性3つ: 土, 炎, 吸収

## 簡単な説明文

味方が倒すとゲージが増え、満ちると、その味方の次の風の攻撃が強くなる。

## 詳細な説明文

敵が対象を選ぶ行動では、ヨシノのターゲット優先度として、各種ステータスの表の値を使う。この値が高いほど、ヨシノが選ばれやすい。ヨシノ以外の味方が選ばれる確率は、ヨシノとその味方のターゲット優先度の差が大きいほど低くなる。ターゲット優先度の星倍率は★1から★4まで1なので、★2以降が空欄のときは★1の値96を使う。

ゲージは1つで、最大は100である。100を超えた分は消え、ゲージは0になる。50と100は、星では変わらない。戦闘が終わっても、ヨシノの体力が0以下になっても、ゲージの量は残る。体力が0以下のあいだは、ゲージは増えない。

戦闘開始時に、ゲージがさらに入る。入る量は、効果値の開始時のゲージの欄にある、ヨシノの星の値である。★1は30、★2は36、★3は45、★4は51である。この欄は%ではない。前の戦闘から残っている量があるときは、その量に、この量が加わる。加えた結果が100以上になるときは、99で止まる。この追加では、次の風の攻撃は残らない。倒したときに増える分とは別である。

味方の攻撃で敵の体力が0以下になったとき、その1体につきゲージが増える。これは倒したときである。撃破ゲージが0になったときとは別である。継続ダメージでは増えない。ヨシノ自身が倒したときも、ほかの味方が倒したときも、増える量はビストロンのままである。同じ倒しで2回は入らない。2人より少ないときは50である。2人のときは60、4人のときは70、6人のときは80、8人のときは90である。人数が段階のあいだのときは、その人数より少ない段階のうち最も近い段階を使う。後衛にいても、味方の倒しでは増える。同じ攻撃で倒した分は、全部入れてから100を1回確かめる。ヨシノが複数いるときは、体力が0より大きいヨシノそれぞれのゲージが、この量だけ増える。

100になったとき、その倒しをした味方の、次の風の攻撃が強くなる。強くなるのは、その風属性の攻撃の与ダメージである。ヨシノ自身が倒したときは、ヨシノの次の風の攻撃である。高くなる割合は、効果値の次の風の攻撃の欄にある、100になったヨシノの星の値である。★1は25%、★2は30%、★3は38%、★4は43%である。100にした攻撃には入らない。継続ダメージには入らない。すでに次の風の攻撃が残っているときに、もう一度100になっても、次の風の攻撃は1つのままである。先に決めた味方が残る。同じ味方に、複数のヨシノから次の風の攻撃が残るときは、星が最も高いヨシノの割合を使う。同じ星のときは、IDが小さいヨシノである。

その1回の風の攻撃は、貫通率も高くなる。高くなる割合は、効果値の次の風の貫通率の欄にある、100になったヨシノの星の値である。★1は10%、★2は12%、★3は15%、★4は17%である。ポプリの貫通率とは別である。バフの貫通率とも別である。あるものは、すべて入る。継続ダメージには入らない。

その味方が風属性の攻撃をすると、外れても、その1回は終わる。バフとガードでは終わらない。その味方の体力が0以下になると、残っていた次の風の攻撃は消える。ヨシノの体力が0以下になっても、すでに決まった次の風の攻撃は残る。戦闘が終わっても、その味方が風属性の攻撃をするまで残る。

## バフ/デバフ

バフ。体力が0より大きい味方のうち、現在の体力が最も高い1体は、貫通率が高くなる。同じ体力のときは、IDが小さい味方である。ヨシノ自身も入る。高くなる割合は、効果値のバフの貫通率の欄にある、ヨシノの星の値である。★1は8%、★2は10%、★3は12%、★4は14%である。ポプリの貫通率とは別である。次の風の貫通率とも別である。あるものは、すべて入る。同時に1体だけで、別の味方へバフしたとき、または対象かヨシノの体力が0以下になったときに消える。

隣にいる味方は、与ダメージが高くなる。隣は、同じ段のすぐ左とすぐ右である。前衛なら前衛、後衛なら後衛である。端で隣がいない側は入らない。ヨシノ自身は入らない。高くなる割合は、効果値の隣の与ダメージの欄にある、ヨシノの星の値である。★1は4%、★2は5%、★3は6%、★4は7%である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。ヨシノの体力が0より大きいあいだ、行動を選ばなくても入る。ヨシノか隣の体力が0以下のとき、または隣でなくなったときに消える。
