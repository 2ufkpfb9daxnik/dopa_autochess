# 洗練されたバクパク

- ID: 004
- 名前: 洗練されたバクパク
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備しているあいだ、最大体力が高くなる。

## 詳細な説明文

このレリックを装備したとき、装備しているキャラクターの最大体力が高くなる。いまの体力も、同じ量だけ高くなる。新しい最大体力は超えない。高くなる量は、効果値の最大体力の欄の値である。25である。この欄は%ではない。外すと、この上昇は消える。いまの体力は、新しい最大体力を超えない。
