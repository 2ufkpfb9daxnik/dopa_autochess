# どうも

- ID: 005
- 名前: どうも
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備しているあいだ、クリティカル率が高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、クリティカル率が高くなる。高くなる量は、効果値のクリティカル率の欄の値である。15である。この欄は%ではない。シートのクリティカル率に、この値が入る。外しても消える。
