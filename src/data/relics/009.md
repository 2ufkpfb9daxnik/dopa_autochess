# POPなお菓子

- ID: 009
- 名前: POPなお菓子
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

攻撃が当たると、体力が戻る。

## 詳細な説明文

このレリックを装備しているキャラクターの通常の攻撃が命中したとき、そのキャラクターの体力が戻る。戻る量は、そのときの最大体力のうち、効果値の回復の欄の割合である。8%である。外れでは戻らない。ガードで当たった攻撃では戻る。範囲ダメージだけでは戻らない。1戦闘で戻る回数は、効果値の回復の回数の欄の値までである。3である。この欄は%ではない。上限のあとは戻らない。最大体力は超えない。継続ダメージでは戻らない。
