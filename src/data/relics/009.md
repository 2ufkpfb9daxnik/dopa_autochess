# POPなお菓子

- ID: 009
- 名前: POPなお菓子
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

通常の攻撃が当たると、最大体力の8%だけ体力が戻る。1戦闘で3回まで。

## 詳細な説明文

このレリックを装備しているキャラクターの通常の攻撃が命中したとき、そのキャラクターの最大体力の8%だけ体力が戻る。外れでは戻らない。ガードで当たった攻撃では戻る。範囲ダメージだけでは戻らない。1戦闘で3回まで戻る。上限のあとは戻らない。最大体力は超えない。継続ダメージでは戻らない。
