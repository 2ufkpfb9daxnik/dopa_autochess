# 見ないアート

- ID: 010
- 名前: 見ないアート
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

その戦闘の最初の攻撃は外れず、強くなる。

## 詳細な説明文

このレリックを装備しているキャラクターの、その戦闘での最初の通常の攻撃は外れない。その攻撃の与ダメージは25%高くなる。通常の攻撃と、その範囲ダメージに入る。継続ダメージには入らない。ガードで当たることはある。バフとガードの行動では、この1回は終わらない。最初の通常の攻撃をしたら、外れなくても、この1回は終わる。
