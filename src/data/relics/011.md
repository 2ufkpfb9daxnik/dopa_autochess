# 挨拶

- ID: 011
- 名前: 挨拶
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

敵を倒すと、もう1回攻撃する。

## 詳細な説明文

このレリックを装備しているキャラクターの通常の攻撃で、敵の体力が0以下になったとき、そのキャラクターが通常の攻撃をもう1回出す。行動にはならない。行動ポイントは変わらない。1戦闘で1回まで戻る。対象は、生きている前衛のうち、ターゲット優先度がいちばん高い敵である。同じ優先度のときは、IDが小さい敵である。前衛がいないときは出ない。1回ごとに命中を見る。攻撃力も与ダメージも、そのキャラクターの、そのときの通常の攻撃である。範囲と継続は、そのキャラクターの通常の攻撃のままである。
