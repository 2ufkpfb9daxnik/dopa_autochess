# 物語はこれでおしまい

- ID: 012
- 名前: 物語はこれでおしまい
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

自分の攻撃属性の撃破が、さらに進む。

## 詳細な説明文

このレリックを装備しているキャラクターが、自分の攻撃属性で通常の攻撃をしたとき、対象のその属性の撃破ゲージが、ふつうの1回分さらに減る。撃破シナジーに入っていなくても減る。入っているときは、ふつうの減少に加えて、この1回分が減る。減らす量と上限は、ここでは決めない。すでに0のときは減らさない。途中で0になったあとの余分な減少は起きない。外れても減る。範囲の端だけでは減らない。継続ダメージでは減らない。撃破ダメージではない。
