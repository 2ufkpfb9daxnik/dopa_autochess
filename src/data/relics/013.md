# ヨガの極

- ID: 013
- 名前: ヨガの極
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

攻撃が当たると、自分の攻撃属性の層が付く。

## 詳細な説明文

このレリックを装備しているキャラクターの通常の攻撃が命中したとき、対象に、そのキャラクターの攻撃属性の層が1付く。継続シナジーに入っていなくても付く。入っているときは、シナジーで付く1層とは別に付く。外れでは付かない。ガードで当たった攻撃では付く。範囲の端には付かない。継続ダメージでは付かない。継続ダメージの攻撃力は、そのキャラクターの攻撃力である。割合は、その属性の継続シナジーの段階である。書き写さない。1人のときは、その属性のいちばん低い段階の割合である。
