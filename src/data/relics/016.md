# オーダーメイド

- ID: 016
- 名前: オーダーメイド
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

通常の攻撃の範囲に、狙った前衛の隣が入る。

## 詳細な説明文

このレリックを装備しているキャラクターの通常の攻撃では、狙った敵が前衛のとき、その隣の前衛にも範囲ダメージが入る。隣は、同じ段のすぐ左かすぐ右である。生きている隣が2体のときは、IDが小さい1体である。端で隣がいないときは、この追加はない。狙った敵が後衛のときは、この追加はない。この1体は、範囲シナジーの体数とは別である。範囲シナジーがなくても出る。範囲シナジーがあるときも、この1体は別に入る。命中は1体ごとに見る。属性は、そのキャラクターの攻撃属性である。
