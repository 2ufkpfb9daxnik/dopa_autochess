# 異邦人

- ID: 017
- 名前: 異邦人
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

攻撃が当たった敵の、次の攻撃が弱くなる。

## 詳細な説明文

このレリックを装備しているキャラクターの通常の攻撃が命中したとき、その対象が与えるダメージは、次の通常の攻撃1回だけ低くなる。低くなる割合は、効果値の次の与ダメージの欄の値である。15%である。通常の攻撃と、その範囲ダメージに入る。継続ダメージには入らない。外れでは入らない。ガードで当たった攻撃では入る。範囲の端だけでは入らない。その1回が外れても、そこで終わる。同時に1体だけで、別の敵へ入ったとき、前の分は消える。対象か装備者の体力が0以下になったときも消える。
