# 地球儀

- ID: 018
- 名前: 地球儀
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

攻撃するたび、速度が4高くなる。上限は12。

## 詳細な説明文

このレリックを装備しているキャラクターの通常の攻撃が終わったあと、そのキャラクターの速度が1回あたり4、上限12まで高くなる。上限を超える分は入らない。外れても上がる。バフとガードの行動では上がらない。行動の間隔は、その速度で決まる。いま残っている行動ポイントは変わらない。戦闘が終わると、この上昇は消える。外しても消える。
