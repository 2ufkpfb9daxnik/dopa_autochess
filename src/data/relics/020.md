# 青写真

- ID: 020
- 名前: 青写真
- 分類: 戦闘中の個体効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

体力が半分以下のとき、与えるダメージが高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターの、いまの体力が最大体力の半分以下のとき、与えるダメージが25%高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。半分ちょうどでも入る。整数にならない最大体力の半分は、半分以上の端数を切り上げた値である。体力が半分より大きいときは入らない。外しても消える。
