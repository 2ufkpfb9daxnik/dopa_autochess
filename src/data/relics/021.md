# ナショナル殿下

- ID: 021
- 名前: ナショナル殿下
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備しているあいだ、味方全員の与ダメージが8%高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、味方全員の与ダメージが8%高くなる。装備者自身も入る。通常の攻撃、その範囲ダメージ、継続ダメージに入る。装備者の体力が0以下のときと、外したときに消える。同じレリックが複数あるときは1つだけ入る。IDが小さい方である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 8 |
