# 模型

- ID: 023
- 名前: 模型
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備しているあいだ、味方全員が受けるダメージが8%低くなる。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、味方全員が攻撃で受けるダメージが低くなる。装備者自身も入る。8%低くなる。継続ダメージには入らない。装備者の体力が0以下のときと、外したときに消える。同じレリックが複数あるときは1つだけ入る。IDが小さい方である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受けるダメージ | 8 |
