# 簡約

- ID: 024
- 名前: 簡約
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備しているあいだ、前衛の味方の防御力が25高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、前衛の味方の防御力が25高くなる。装備者が前衛なら、装備者も入る。後衛は入らない。装備者の体力が0以下のときと、外したときに消える。同じレリックが複数あるときは1つだけ入る。IDが小さい方である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 防御力 | 25 |
