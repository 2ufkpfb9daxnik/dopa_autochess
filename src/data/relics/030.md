# 画鋲

- ID: 030
- 名前: 画鋲
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方の攻撃が当たると、装備者の属性の撃破が進む。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、味方の通常の攻撃が命中したとき、その対象の、装備者の攻撃属性の撃破ゲージが、ふつうの1回分減る。撃破シナジーに入っていなくても減る。入っているときは、ふつうの減少に加えて減る。減らす量と上限は、ここでは決めない。すでに0のときは減らさない。外れでは減らない。範囲の端だけでは減らない。継続ダメージでは減らない。撃破ダメージではない。1戦闘で3回まで戻る。装備者の体力が0以下のときは減らない。同じレリックが複数あるときは1つだけ入る。IDが小さい方である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 撃破の回数 | 3 |
