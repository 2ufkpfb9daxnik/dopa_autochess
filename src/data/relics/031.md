# K->C

- ID: 031
- 名前: K->C
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方のクリティカルが当たると、装備者の属性の層が付く。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、味方の通常の攻撃がクリティカルし、命中したとき、その対象に、装備者の攻撃属性の層が付く。付く数は、効果値の層の欄の値である。1である。この欄は%ではない。外れでは付かない。ガードで当たった攻撃では付く。範囲の端だけでは付かない。継続ダメージでは付かない。1戦闘で付けられる回数は、効果値の層の回数の欄の値までである。3である。この欄は%ではない。継続ダメージの攻撃力は、装備者の攻撃力である。割合は、その属性の継続シナジーの段階である。書き写さない。1人のときは、その属性のいちばん低い段階の割合である。装備者の体力が0以下のときは付かない。同じレリックが複数あるときは、1つだけ入る。IDが小さい方である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 層 | 1 |
| 層の回数 | 3 |
