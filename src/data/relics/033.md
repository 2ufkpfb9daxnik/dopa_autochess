# 漏洩

- ID: 033
- 名前: 漏洩
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者が被弾すると、ほかの前衛が次に受けるダメージが12%低くなる。

## 詳細な説明文

このレリックを装備しているキャラクターが前衛にいて、攻撃を受けて命中したとき、装備者以外の前衛の味方が次に受ける攻撃1回のダメージが12%低くなる。継続ダメージには入らない。外れでは入らない。ガードで当たった被弾では入る。すでに入っているあいだにもう一度被弾しても、1回のままである。その1回が外れたときは、回数は減らない。装備者が後衛のときは入らない。同じレリックが複数あるときは1つだけ入る。IDが小さい方である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受けるダメージ | 12 |
