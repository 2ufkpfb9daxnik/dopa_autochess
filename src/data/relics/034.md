# パイプ

- ID: 034
- 名前: パイプ
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備しているあいだ、味方全員の貫通率が高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、味方全員の貫通率が高くなる。装備者自身も入る。高くなる割合は、効果値の貫通率の欄の値である。8%である。通常の攻撃と、その範囲ダメージに入る。継続ダメージには入らない。貫通率は合計し、100%で止まる。装備者の体力が0以下のときと、外したときに消える。同じレリックが複数あるときは、1つだけ入る。IDが小さい方である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 貫通率 | 8 |
