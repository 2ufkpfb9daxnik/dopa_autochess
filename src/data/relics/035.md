# 葉脈

- ID: 035
- 名前: 葉脈
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

前衛がガードすると、隣の前衛も受けるダメージが15%低くなる。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、前衛の味方がガードの行動をしているとき、その隣の前衛が攻撃で受けるダメージが低くなる。隣は、同じ段のすぐ左とすぐ右である。端で隣がいない側は入らない。後衛は入らない。15%低くなる。継続ダメージには入らない。ガードしている本人には、この隣の低下は入らない。ガードが終わると消える。装備者の体力が0以下のときは入らない。同じレリックが複数あるときは1つだけ入る。IDが小さい方である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受けるダメージ | 15 |
