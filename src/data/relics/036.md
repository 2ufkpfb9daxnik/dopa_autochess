# 自動再生

- ID: 036
- 名前: 自動再生
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

戦闘の途中で、いちばん体力が低い味方の体力が戻る。

## 詳細な説明文

このレリックを装備しているキャラクターが出ている戦闘で、味方全体の行動が、効果値の行動の数の欄の値だけ終わったとき、いまの体力の割合がいちばん低い味方の体力が戻る。同じ割合のときは、IDが小さい味方である。戻る量は、その味方の最大体力のうち、効果値の回復の欄の割合である。12%である。行動の数は4である。この欄は%ではない。最大体力は超えない。1戦闘で1回だけである。装備者が戦闘に出ていなければ入らない。同じレリックが複数あるときは、1つだけ入る。IDが小さい方である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回復 | 12 |
| 行動の数 | 4 |
