# シマウマ

- ID: 038
- 名前: シマウマ
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

敵のデバフを、一定回数まで無効にする。

## 詳細な説明文

このレリックを装備しているキャラクターが出ている戦闘の開始時、敵が味方に付けるデバフを無効にできる回数が残る。回数は2である。敵キャラクターが味方にデバフを付けるとき、残り回数が1以上なら、そのデバフを無効にする。無効にしたデバフは味方に付かない。敵のその行動は、使ったままになる。1体へのデバフを無効にするたびに、残り回数を1減らす。対象が複数のときは1体につき1減らす。残り回数が0のあとは無効にしない。攻撃のダメージ、継続ダメージの層、撃破ゲージは、それぞれの通常の効果のままである。戦闘開始前から付いているデバフは残る。装備者が戦闘に出ていなければ、回数は残らない。同じレリックが複数あるときは、回数は1つ分だけである。IDが小さい方である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 無効の回数 | 2 |
