# ガエル

- ID: 039
- 名前: ガエル
- 分類: 戦闘中の部隊効果
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者と隣の味方は、狙われやすくなる。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、装備者と、その隣の味方のターゲット優先度が高くなる。隣は、同じ段のすぐ左とすぐ右である。前衛なら前衛、後衛なら後衛である。端で隣がいない側は入らない。高くなる量は、効果値の優先度の上昇の欄の値である。20である。この欄は%ではない。装備者の体力が0以下のときと、外したときと、隣でなくなったときに消える。同じレリックが複数あるときは、それぞれ別の装備者とその隣に入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 優先度の上昇 | 20 |
