# 窓使いの憂鬱

- ID: 044
- 名前: 窓使いの憂鬱
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

売るたびに、売却額とは別にゴールドが入る。回数を使い切ると消える。

## 詳細な説明文

このレリックを持っているあいだ、キャラクターを売るたびに、売却額とは別にゴールドが入る。入る量は、効果値のゴールドの欄の値である。1である。この欄は%ではない。入るたびに残り回数を1減らす。残り回数の最初は、効果値の回数の欄の値である。5である。残り回数が0になると、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 1 |
| 回数 | 5 |
