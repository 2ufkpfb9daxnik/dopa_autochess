# 隠遁生活

- ID: 046
- 名前: 隠遁生活
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

数ラウンドのあいだ、入る利息が多い。終わると消える。

## 詳細な説明文

このレリックを入手したときから、4ラウンドのあいだ、戦闘終了時に入る利息のゴールドが1多い。ラウンドは4である。利息は1である。基本の利息の計算のあとに足す。ラウンド数を使い切ると、このレリックは消える。風力とは別である。両方あるときは両方入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ラウンド | 4 |
| 利息 | 1 |
