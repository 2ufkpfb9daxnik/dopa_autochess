# ネット・ワーク

- ID: 049
- 名前: ネット・ワーク
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

同じコストを2体以上買ったラウンド、無料更新が1回入手できる。

## 詳細な説明文

このレリックを持っているあいだ、同じコストのキャラクターを、そのラウンドに2体以上買ったとき、無料更新が1回入手できる。同じラウンドで条件を満たしても、獲得は1回までである。コストが違えば別である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 無料更新 | 1 |
