# 鳥

- ID: 052
- 名前: 鳥
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

経験値購入の費用が1安い。回数を使い切ると消える。

## 詳細な説明文

このレリックを持っているあいだ、経験値をゴールドで買う費用が安くなる。安くなる量は、効果値の値引きの欄の値である。1である。この欄は%ではない。基本の経験値購入は、4ゴールドで経験値4である。買うたびに残り回数を1減らす。残り回数の最初は、効果値の回数の欄の値である。10である。残り回数が0になると、このレリックは消える。石庭とは別である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 値引き | 1 |
| 回数 | 10 |
