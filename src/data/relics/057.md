# 月へ行ってみよう

- ID: 057
- 名前: 月へ行ってみよう
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

有料更新の費用が1安い。回数を使い切ると消える。

## 詳細な説明文

このレリックを持っているあいだ、有料のショップ更新の費用が安くなる。安くなる量は、効果値の値引きの欄の値である。1である。この欄は%ではない。基本の更新費用は2である。有料更新するたびに残り回数を1減らす。残り回数の最初は、効果値の回数の欄の値である。5である。残り回数が0になると、このレリックは消える。無料更新を消費する更新には入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 値引き | 1 |
| 回数 | 5 |
