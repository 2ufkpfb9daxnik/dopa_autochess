# 展望

- ID: 059
- 名前: 展望
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

コスト5、6、7のキャラクターを買ったとき、星と同じ数だけゴールドが戻る。

## 詳細な説明文

このレリックを持っているあいだ、コストが5、6、7のいずれかのキャラクターを買ったとき、そのキャラクターの星と同じ数だけゴールドが戻る。★1なら1、★2なら2、★3なら3、★4なら4である。星1あたりの戻りは1ゴールドである。コストが4以下のときは戻らない。買うときに支払ったあと、すぐに戻る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 戻りゴールド | 1 |
