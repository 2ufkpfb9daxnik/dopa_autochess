# アラーム

- ID: 062
- 名前: アラーム
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

有料更新したとき、しばしば無料更新を獲得する。

## 詳細な説明文

このレリックを持っているあいだ、ゴールドを払ってショップを更新したとき、無料更新を獲得することがある。合計10回のうち、効果値の当たりの欄の値の回数で獲得する。4である。この欄は%ではない。獲得する数は、効果値の無料更新の欄の値である。1である。連続して当たってもよい。無料更新を消費する更新には入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 当たり | 4 |
| 無料更新 | 1 |
