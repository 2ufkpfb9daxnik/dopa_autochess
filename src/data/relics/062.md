# アラーム

- ID: 062
- 名前: アラーム
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

有料更新したとき、しばしば無料更新が1回入手できる。

## 詳細な説明文

このレリックを持っているあいだ、ゴールドを払ってショップを更新したとき、無料更新を獲得することがある。合計10回のうち4回当たり、無料更新が1回入手できる。連続して当たってもよい。無料更新を消費する更新には入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 当たり | 4 |
| 無料更新 | 1 |
