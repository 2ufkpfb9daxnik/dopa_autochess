# ワイル・E・コヨーテ

- ID: 063
- 名前: ワイル・E・コヨーテ
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

ラウンド開始時、所持ゴールドが多いほど無料更新を獲得する。

## 詳細な説明文

このレリックを持っているあいだ、ラウンド開始時の所持ゴールドに応じて、無料更新を獲得する。所持が40以上なら2、20以上40未満なら1、20未満なら0である。効果値の多い段の欄は40、少ない段の欄は20である。この欄は%ではない。ワンパターンの毎ラウンドの無料更新とは別である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 多い段 | 40 |
| 少ない段 | 20 |
