# デューンパッケージ

- ID: 065
- 名前: デューンパッケージ
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

利息の計算で、所持ゴールドが8多いものとして扱われる。

## 詳細な説明文

このレリックを持っているあいだ、戦闘終了時の利息を計算するとき、実際の所持ゴールドに8を足した額で利息を出す。利息の元手の上限は、そのときのプレイヤーレベルに10を掛けた数までである。8を足したあとも、その上限を超えたぶんは利息に使わない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 元手 | 8 |
