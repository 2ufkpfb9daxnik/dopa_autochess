# デューンパッケージ

- ID: 065
- 名前: デューンパッケージ
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

利息に数えるゴールドが多く扱われる。

## 詳細な説明文

このレリックを持っているあいだ、利息を計算するとき、所持ゴールドに加えて、8だけ多いものとして数える。8である。利息に数えるゴールドの上限は、そのときのプレイヤーレベルに10を掛けた数までである。足したあとも、その上限を超えては数えない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 元手 | 8 |
