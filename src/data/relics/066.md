# ビーチ

- ID: 066
- 名前: ビーチ
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

入手から3ラウンドのあいだ、毎ラウンドゴールドが2入る。3回入るとこのレリックは消える。

## 詳細な説明文

このレリックを入手したときから、3ラウンドのあいだ、ラウンド開始時にゴールドが入る。入る量は2である。ゴールドが入るたびに残りラウンドを1減らす。残りラウンドの最初は3である。3回入って残りが0になると、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ラウンド | 3 |
| ゴールド | 2 |
