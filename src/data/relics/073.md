# トスコ

- ID: 073
- 名前: トスコ
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

レベルが上がったとき、そのレベルと同じ数だけ無料更新を獲得する。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤーレベルが上がったとき、上がったあとのレベルと同じ数だけ無料更新を獲得する。レベルが1上がるたびに1回である。1である。一度に2以上上がったときは、上がったあとのレベルと同じ数だけである。途中のレベルぶんは足さない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 倍率 | 1 |
