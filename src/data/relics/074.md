# 石庭

- ID: 074
- 名前: 石庭
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

経験値を買うと、経験値が少し多い。

## 詳細な説明文

このレリックを持っているあいだ、経験値をゴールドで買うとき、入る経験値が、効果値の経験値の欄の値だけ多い。1である。この欄は%ではない。基本は4ゴールドで経験値4である。このレリックがあるときは、同じ費用で経験値5である。鳥の値引きとは別である。両方あるときは両方入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 経験値 | 1 |
