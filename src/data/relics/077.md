# 再呼び出し

- ID: 077
- 名前: 再呼び出し
- 分類: ショップ・通貨・購入
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

利息に数えるゴールドの上限に届いていないとき、足りない分が入る。回数を使い切ると消える。

## 詳細な説明文

このレリックを持っているあいだ、ラウンド開始時に、所持ゴールドが利息に数えるゴールドの上限より少ないとき、足りない分だけゴールドが入る。上限は、そのときのプレイヤーレベルに10を掛けた数である。入るたびに残り回数を1減らす。残り回数の最初は、効果値の回数の欄の値である。2である。この欄は%ではない。残り回数が0になると、このレリックは消える。すでに上限以上のときは入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回数 | 2 |
