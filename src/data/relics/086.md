# 確率

- ID: 086
- 名前: 確率
- 分類: 経験値・レベル・出現率
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

ショップを更新するたび、1枠は盤面のキャラクターから必ず出る。

## 詳細な説明文

このレリックを持っているあいだ、ショップを更新したとき、並びのうち無作為な1枠は、そのとき盤面にいる味方キャラクターから無作為に1体を選び、同じキャラクターを出す。効果値の枠の欄の値は1である。この欄は%ではない。盤面に味方がいないときは、この上書きはしない。ほかの枠は、通常の出現率のままである。有料更新でも、無料更新を消費する更新でも入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 枠 | 1 |
