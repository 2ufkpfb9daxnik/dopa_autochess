# パレード

- ID: 090
- 名前: パレード
- 分類: 経験値・レベル・出現率
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

プレイヤーレベルの上限が1上がる。入手時に経験値も入る。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤーレベルの上限が1だけ上がる。1である。基本の上限は20である。このレリックがあるときは21である。入手したとき、経験値が8入る。外したとき、上限の上昇は消える。すでに21のときは、経験値だけが入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 上限 | 1 |
| 経験値 | 8 |
