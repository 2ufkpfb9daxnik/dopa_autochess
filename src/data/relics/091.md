# パラダイス！

- ID: 091
- 名前: パラダイス！
- 分類: 経験値・レベル・出現率
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

出撃上限が1多い。負けると、受けるプレイヤーダメージが1多い。

## 詳細な説明文

このレリックを持っているあいだ、サークルに出せるキャラクターの上限が、プレイヤーレベルとは別に、効果値の出撃の欄の値だけ多い。1である。この欄は%ではない。プレイヤー同士の戦闘に負けたとき、受けるプレイヤーダメージが、効果値のダメージの欄の値だけ多い。1である。勝ったときと引き分けのときは増えない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 出撃 | 1 |
| ダメージ | 1 |
