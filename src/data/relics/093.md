# 馬蹄

- ID: 093
- 名前: 馬蹄
- 分類: 経験値・レベル・出現率
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

利息がすべて経験値になる。

## 詳細な説明文

このレリックを持っているあいだ、戦闘終了時に入るはずの利息はゴールドとしては入らない。そのかわり、同じ量の経験値がラウンド開始時に入る。風力や隠遁生活、月2-263、ダイトーの利息増加も、変えたあとの経験値に含まれる。フィックスがあるときは利息自体が消えるので、この変換も働かない。
