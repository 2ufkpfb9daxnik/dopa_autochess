# 小群

- ID: 095
- 名前: 小群
- 分類: 経験値・レベル・出現率
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

経験値購入を、ゴールドの代わりにプレイヤーHPで払える。

## 詳細な説明文

このレリックを持っているあいだ、経験値を買うとき、ゴールドの代わりにプレイヤーHPを支払える。1回あたりの支払いは5である。入る経験値は、基本どおり4である。HPが支払いに足りないときは、この払いかたはできない。ゴールドでの購入も、これまでどおりできる。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| HP | 5 |
