# 通過

- ID: 096
- 名前: 通過
- 分類: 経験値・レベル・出現率
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

数ラウンドのあいだ、ショップ出現率がレベル1高い表と同じになる。終わると消える。

## 詳細な説明文

このレリックを入手したときから、3ラウンドのあいだ、ショップの出現率は、プレイヤーレベルが1高いときの表と同じである。ラウンドは3である。レベルが上限のときは、上限の表のままである。ラウンド数を使い切ると、このレリックは消える。ラジオとは別である。両方あるときは、高い方の扱いだけ入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ラウンド | 3 |
