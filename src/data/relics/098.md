# パイロット・ラン

- ID: 098
- 名前: パイロット・ラン
- 分類: 経験値・レベル・出現率
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

一定ラウンドごとに、経験値と無料更新が入る。

## 詳細な説明文

このレリックを持っているあいだ、効果値の間隔の欄の値のラウンドごと、そのラウンドの開始時に経験値と無料更新が入る。間隔は5である。入る経験値は、効果値の経験値の欄の値である。4である。獲得する無料更新は、効果値の無料更新の欄の値である。2である。この欄は%ではない。入手したラウンドを1ラウンド目と数える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 間隔 | 5 |
| 経験値 | 4 |
| 無料更新 | 2 |
