# 雪山

- ID: 099
- 名前: 雪山
- 分類: 経験値・レベル・出現率
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

レベルが上がるたび、HPが回復し、無料更新を獲得する。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤーレベルが上がるたび、プレイヤーHPが、効果値のHPの欄の値だけ回復する。2である。あわせて、無料更新を獲得する。獲得する数は、効果値の無料更新の欄の値である。2である。この欄は%ではない。レベルが1上がるたびに1回である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| HP | 2 |
| 無料更新 | 2 |
