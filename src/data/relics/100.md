# ラジオ

- ID: 100
- 名前: ラジオ
- 分類: 経験値・レベル・出現率
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

次の有料更新数回だけ、ショップ出現率がレベル1高い表と同じになる。使い切ると消える。

## 詳細な説明文

このレリックを持っているあいだ、ゴールドを払ってショップを更新するとき、その並びの出現率は、プレイヤーレベルが1高いときの表と同じである。有料更新するたびに残り回数を1減らす。残り回数の最初は、効果値の回数の欄の値である。3である。この欄は%ではない。レベルが上限のときは、上限の表のままである。残り回数が0になると、このレリックは消える。無料更新を消費する更新には入らない。通過とは別である。両方あるときは、高い方の扱いだけ入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回数 | 3 |
