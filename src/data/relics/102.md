# パンドラ

- ID: 102
- 名前: パンドラ
- 分類: 合成・売却・複製
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

毎ラウンド、控えのいちばん下の列が、同じコスト・同じ星の別キャラクターに入れ替わる。

## 詳細な説明文

このレリックを持っているあいだ、ラウンド開始時に、控えのいちばん下の列にあるキャラクターが、それぞれ同じコストの別キャラクターに入れ替わる。星は入れ替わる前と同じである。効果値の列の枠の欄の値は3である。この欄は%ではない。控えは横3枠の列が並ぶ。いちばん下の列に空きがある枠は入れ替わらない。同じキャラクターにはならない。同じコストの別キャラクターがいないときは、その枠は入れ替わらない。ゴールドが、効果値のゴールドの欄の値だけ入る。1である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 列の枠 | 3 |
| ゴールド | 1 |
