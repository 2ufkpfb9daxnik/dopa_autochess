# 宇宙船

- ID: 103
- 名前: 宇宙船
- 分類: 合成・売却・複製
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

次に選んだコスト3以下のキャラクターを1体複製する。使ったら消える。

## 詳細な説明文

このレリックを持っているあいだ、手元のキャラクター1体を選んで複製できる。選んだキャラクターのコストが、効果値の上限コストの欄の値以下のときだけである。3である。この欄は%ではない。複製は、同じキャラクター・同じ星で1体入る。装備やレリックは複製しない。複製したあと、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 上限コスト | 3 |
