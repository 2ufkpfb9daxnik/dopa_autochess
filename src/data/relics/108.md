# 西通り

- ID: 108
- 名前: 西通り
- 分類: 合成・売却・複製
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

盤面のキャラクターが、コストが1高い無作為なキャラクターに変わる。星は残る。1回で消える。

## 詳細な説明文

このレリックを使うと、そのとき盤面にいる味方キャラクターが、それぞれコストが1高い無作為なキャラクターに変わる。星は変わる前と同じである。1である。変わる先のコストが、そのときの合成上限を超えるときは、合成上限のコストのキャラクターになる。コスト7のキャラクターは変わらない。装備やレリックはそのキャラクターに残る。使ったあと、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| コスト上昇 | 1 |
