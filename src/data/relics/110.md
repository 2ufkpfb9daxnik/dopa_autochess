# コンダクター

- ID: 110
- 名前: コンダクター
- 分類: 合成・売却・複製
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

次の異種合成数回だけ、合成上限を見ない。使い切ると消える。

## 詳細な説明文

このレリックを持っているあいだ、異種合成するとき、合成上限を見ない。結果のコストは、素材のコストの和のままである。結果のキャラクターは、通常どおり合成先の表で決まる。異種合成するたびに残り回数を1減らす。残り回数の最初は、効果値の回数の欄の値である。2である。この欄は%ではない。残り回数が0になると、このレリックは消える。同種合成には入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回数 | 2 |
