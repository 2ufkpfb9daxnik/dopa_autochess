# トランスポーズ

- ID: 115
- 名前: トランスポーズ
- 分類: 合成・売却・複製
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

次の異種合成の結果を、同じコスト・同じ星の別の合成先に1回差し替えられる。使ったら消える。

## 詳細な説明文

このレリックを持っているあいだ、次の異種合成1回だけ、結果が決まったあと、同じコストの別キャラクターへ差し替えられる。星は、その異種合成の結果の星のままである。効果値の回数の欄の値は1である。この欄は%ではない。差し替え先は、そのコストに存在するキャラクターから選ぶ。合成先の表に無い組み合わせでも、コストと星だけ合わせる。差し替えたあと、このレリックは消える。同種合成には入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回数 | 1 |
