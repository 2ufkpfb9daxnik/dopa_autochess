# 雨粒

- ID: 116
- 名前: 雨粒
- 分類: 合成・売却・複製
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

数ラウンドのあいだ、合成上限が1高い。終わると消える。

## 詳細な説明文

このレリックを入手したときから、効果値のラウンドの欄の値のラウンド数だけ、異種合成の合成上限が、効果値の上限の欄の値だけ高い。ラウンドは3である。上限は1である。この欄は%ではない。ラウンド数を使い切ると、このレリックは消える。自動起動とは別である。両方あるときは両方入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ラウンド | 3 |
| 上限 | 1 |
