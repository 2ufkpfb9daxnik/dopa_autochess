# カーニバル

- ID: 117
- 名前: カーニバル
- 分類: 合成・売却・複製
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

キャラクターを売ったとき、同じコスト・同じ星の無作為なキャラクターが控えに入る。回数を使い切ると消える。

## 詳細な説明文

このレリックを持っているあいだ、キャラクターを売ったとき、売却は通常どおり行い、さらに同じコストで同じ星の無作為なキャラクターが控えに1体入る。星は売ったキャラクターと同じである。売ったのと同じキャラクターにはならない。効果値の回数の欄の値の回数だけ入る。5である。この欄は%ではない。入るたびに残り回数を1減らす。残り回数が0になると、このレリックは消える。控えが満杯のときは入らない。そのときは残り回数は減らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回数 | 5 |
