# イヤードラム

- ID: 119
- 名前: イヤードラム
- 分類: 合成・売却・複製
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

次の異種合成数回だけ、結果のコストが1高い合成先になる。使い切ると消える。

## 詳細な説明文

このレリックを持っているあいだ、異種合成の結果は、素材のコストの和に、1を足したコストの合成先になる。コスト上昇は1である。そのコストが合成上限を超えるときは、合成上限のコストの合成先になる。星は、通常どおり低い方である。余剰価値のコインも、この結果で計算する。異種合成するたびに残り回数を1減らす。残り回数の最初は2である。残り回数が0になると、このレリックは消える。同種合成には入らない。結果のキャラクターは、そのコスト帯の合成先の表で決まる。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| コスト上昇 | 1 |
| 回数 | 2 |
