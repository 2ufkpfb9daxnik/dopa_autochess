# 正午

- ID: 121
- 名前: 正午
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

負けたあと、ゴールドと無料更新が入る。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤー同士の戦闘に負けたあと、ゴールドが入る。入る量は、効果値のゴールドの欄の値である。2である。あわせて、無料更新を獲得する。獲得する数は、効果値の無料更新の欄の値である。1である。この欄は%ではない。勝ったときと引き分けのときは入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 2 |
| 無料更新 | 1 |
