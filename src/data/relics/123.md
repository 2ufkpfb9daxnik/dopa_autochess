# 羅針

- ID: 123
- 名前: 羅針
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

連勝・連敗の伸びが速い。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤー同士の戦闘の勝敗で連勝または連敗が増えるとき、増える量が、効果値の倍率の欄の値倍である。2である。この欄は%ではない。1勝で連勝が2増え、1敗で連敗が2増える。連が途切れて反対側が1から始まるときも、その1が2になる。引き分けでは連は増えない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 倍率 | 2 |
