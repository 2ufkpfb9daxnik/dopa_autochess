# ラジアン

- ID: 124
- 名前: ラジアン
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

入手したとき、連勝がまとまって付き、ゴールドも入る。

## 詳細な説明文

このレリックを入手したとき、連勝が、効果値の連勝の欄の値になる。4である。連敗は0になる。あわせてゴールドが入る。入る量は、効果値のゴールドの欄の値である。4である。この欄は%ではない。入ったあと、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 連勝 | 4 |
| ゴールド | 4 |
