# 構築子

- ID: 126
- 名前: 構築子
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

連敗中、味方の与ダメージが高い。

## 詳細な説明文

このレリックを持っているあいだ、連敗が1以上のとき、味方全員の与ダメージが高くなる。高くなる割合は、いまの連敗に、効果値の与ダメージの欄の値を掛けた数である。2である。上限は、効果値の上限の欄の値である。10である。この欄は%である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。連敗が0のときは入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 2 |
| 上限 | 10 |
