# 振動子

- ID: 129
- 名前: 振動子
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

勝ったとき、生き残った味方の数に応じてゴールドが入る。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤー同士の戦闘に勝ったとき、戦闘終了時に体力が0より大きい味方の数を、効果値の人数の欄の値で割った回数だけ、ゴールドが入る。人数は2である。1回あたりのゴールドは、効果値のゴールドの欄の値である。1である。この欄は%ではない。端数は切り捨てる。負けたときと引き分けのときは入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 人数 | 2 |
| ゴールド | 1 |
