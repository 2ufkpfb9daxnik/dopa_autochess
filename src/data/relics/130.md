# 外部宣言

- ID: 130
- 名前: 外部宣言
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

プレイヤーHPが欠けているほど、味方の与ダメージが高い。

## 詳細な説明文

このレリックを持っているあいだ、味方全員の与ダメージが高くなる。高くなる割合は、欠けているプレイヤーHPに、効果値の与ダメージの欄の値を掛けた数である。欠けているプレイヤーHP1につき0.4である。この欄は%である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。プレイヤーHPが最大のときは入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 0.4 |
