# ディスク2

- ID: 132
- 名前: ディスク2
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

次に勝つまで、毎ラウンド無料更新が1回入手できる。勝ったら消える。

## 詳細な説明文

このレリックを持っているあいだ、ラウンド開始時に無料更新が1回入手できる。プレイヤー同士の戦闘に勝ったとき、このレリックは消える。負けても引き分けでも消えない。ワンパターンの毎ラウンドの無料更新とは別である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 無料更新 | 1 |
