# シャッフル

- ID: 133
- 名前: シャッフル
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

連勝または連敗が途切れたとき、ゴールドが3入る。回数を使い切ると消える。

## 詳細な説明文

このレリックを持っているあいだ、連勝が途切れたとき、または連敗が途切れたとき、ゴールドが3入る。入るたびに残り回数を1減らす。残り回数の最初は3である。残り回数が0になると、このレリックは消える。連が0のままのときは入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 3 |
| 回数 | 3 |
