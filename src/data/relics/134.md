# 万能建設機

- ID: 134
- 名前: 万能建設機
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

連勝が長いあいだ勝つと、経験値が2入る。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤー同士の戦闘に勝ったとき、その時点の連勝が3以上なら、経験値が入る。連勝は3である。入る量は2である。勝ったあとの連勝の数で見る。達人の勝敗経験値とは別である。両方あるときは両方入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 連勝 | 3 |
| 経験値 | 2 |
