# ロンド

- ID: 135
- 名前: ロンド
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

連敗が長いあいだ負けると、無料更新を獲得する。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤー同士の戦闘に負けたとき、その時点の連敗が、効果値の連敗の欄の値以上なら、無料更新を獲得する。連敗は3である。獲得する数は、効果値の無料更新の欄の値である。1である。この欄は%ではない。負けたあとの連敗の数で見る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 連敗 | 3 |
| 無料更新 | 1 |
