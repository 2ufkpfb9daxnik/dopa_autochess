# 牛乳

- ID: 136
- 名前: 牛乳
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

最初に勝つまで、味方の与ダメージが高い。勝ったら消える。

## 詳細な説明文

このレリックを持っているあいだ、味方全員の与ダメージが高くなる。高くなる割合は、効果値の与ダメージの欄の値である。8である。この欄は%である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。プレイヤー同士の戦闘に勝ったとき、このレリックは消える。負けても引き分けでも消えない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 8 |
