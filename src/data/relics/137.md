# 増幅器

- ID: 137
- 名前: 増幅器
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

最初に負けるまで、戦闘終了時の利息が1多い。負けたら消える。

## 詳細な説明文

このレリックを持っているあいだ、戦闘終了時に入る利息のゴールドが1多い。基本の利息の計算のあとに足す。プレイヤー同士の戦闘に負けたとき、このレリックは消える。勝っても引き分けでも消えない。風力とは別である。両方あるときは両方入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 利息 | 1 |
