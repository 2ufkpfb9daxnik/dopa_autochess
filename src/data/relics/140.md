# ポスト

- ID: 140
- 名前: ポスト
- 分類: 勝敗・連勝・連敗
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

連が長いあいだ、毎ラウンド追加でゴールドが入る。

## 詳細な説明文

このレリックを持っているあいだ、ラウンド開始時に、いまの連勝または連敗が、効果値の連の欄の値以上なら、ゴールドが入る。連は6である。入る量は、効果値のゴールドの欄の値である。2である。この欄は%ではない。連の収入ボーナスとは別である。両方あるときは両方入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 連 | 6 |
| ゴールド | 2 |
