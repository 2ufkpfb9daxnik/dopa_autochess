# シチュー

- ID: 144
- 名前: シチュー
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者が与えたダメージに応じて、与ダメージが3%高くなる。ラウンドをまたいで残る。

## 詳細な説明文

このレリックを装備しているキャラクターが1回のプレイヤー同士の戦闘で与えたダメージの合計を覚える。800ごとに、与ダメージの積みが1増える。ダメージは800である。端数は切り捨てる。1積みあたりの与ダメージは3%である。積んだぶんだけ、以降の装備者の与ダメージが高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。積みは、このレリックに残る。付け替えても残る。キャラクターが同種合成や異種合成で別の体になっても、このレリックが付いたままなら積みは残る。レリックを合成したときだけ、積みの扱いは合成先のルールに従う。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ダメージ | 800 |
| 与ダメージ | 3 |
