# 香辛料

- ID: 145
- 名前: 香辛料
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方の撃破でも、装備者の与ダメージが積まれる。

## 詳細な説明文

このレリックを装備しているキャラクターが出ている戦闘で、味方が敵を撃破するたび、このレリックの与ダメージの積みが増える。装備者自身の撃破では、効果値の自分の欄の値である。5である。自分以外の味方の撃破では、効果値の味方の欄の値である。3である。この欄は%である。積んだぶんだけ、装備者の与ダメージが高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。装備者が戦闘に出ていなければ増えない。積みは、このレリックに残る。付け替えても残る。キャラクターが同種合成や異種合成で別の体になっても、このレリックが付いたままなら積みは残る。レリックを合成したときだけ、積みの扱いは合成先のルールに従う。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 自分 | 5 |
| 味方 | 3 |
