# 反例

- ID: 148
- 名前: 反例
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者がデバフを受けるたび、あとから受けるデバフが短くなる。

## 詳細な説明文

このレリックを装備しているキャラクターがデバフを受けるたび、このレリックの短縮の積みが増える。1回で増える割合は、効果値の短縮の欄の値である。4である。この欄は%である。積んだぶんだけ、このあとに受けるデバフの残り時間が短くなる。すでに付いているデバフには入らない。積みは、このレリックに残る。付け替えても残る。キャラクターが同種合成や異種合成で別の体になっても、このレリックが付いたままなら積みは残る。レリックを合成したときだけ、積みの扱いは合成先のルールに従う。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 短縮 | 4 |
