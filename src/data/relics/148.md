# 反例

- ID: 148
- 名前: 反例
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者がデバフを受けるたび、このあと受けるデバフの残り時間が4%短くなる。受けるたびに重なる。

## 詳細な説明文

このレリックを装備しているキャラクターがデバフを受けるたび、このレリックが覚える短縮が増える。1回受けるごとに4%増える。増えたぶんだけ、このあとに受けるデバフの残り時間が短くなる。すでに付いているデバフには入らない。短縮は、このレリックに残る。付け替えても残る。キャラクターが同種合成や異種合成で別の体になっても、このレリックが付いたままなら残る。レリックを合成したときだけ、短縮の扱いは合成先のルールに従う。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 短縮 | 4 |
