# アンダーグラウンド

- ID: 150
- 名前: アンダーグラウンド
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

ゴールドを使うほど、装備者の与ダメージが4%高くなる。

## 詳細な説明文

このレリックを装備しているあいだ、プレイヤーがゴールドを支払うたびに、支払った量を覚える。40ごとに、与ダメージの積みが1増える。ゴールドは40である。端数は切り捨てる。1積みあたりの与ダメージは4%である。利息や売却で入ったゴールドでは増えない。支払ったときだけである。積んだぶんだけ、装備者の与ダメージが高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。積みは、このレリックに残る。付け替えても残る。キャラクターが同種合成や異種合成で別の体になっても、このレリックが付いたままなら積みは残る。レリックを合成したときだけ、積みの扱いは合成先のルールに従う。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 40 |
| 与ダメージ | 4 |
