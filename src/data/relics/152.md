# インタビュー

- ID: 152
- 名前: インタビュー
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

プレイヤーレベルが上がるたび、装備者の与ダメージが高くなる。

## 詳細な説明文

このレリックを装備しているあいだ、プレイヤーレベルが上がるたび、このレリックの与ダメージの積みが増える。1回で増える割合は、効果値の与ダメージの欄の値である。8である。この欄は%である。装備していないときにレベルが上がっても増えない。積んだぶんだけ、装備者の与ダメージが高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。積みは、このレリックに残る。付け替えても残る。キャラクターが同種合成や異種合成で別の体になっても、このレリックが付いたままなら積みは残る。レリックを合成したときだけ、積みの扱いは合成先のルールに従う。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 8 |
