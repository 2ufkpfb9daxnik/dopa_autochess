# 袈裟

- ID: 153
- 名前: 袈裟
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

前衛で戦闘を終えるたび、受けるダメージが低くなる。

## 詳細な説明文

このレリックを装備しているキャラクターが、戦闘開始時に前衛で、戦闘終了時に体力が0より大きいとき、このレリックの軽減の積みが増える。1回で増える割合は、効果値の軽減の欄の値である。5である。この欄は%である。積んだぶんだけ、装備者の受けるダメージが低くなる。攻撃のダメージと、その範囲ダメージと、継続ダメージに入る。撃破ゲージの減りかたは変えない。積みは、このレリックに残る。付け替えても残る。キャラクターが同種合成や異種合成で別の体になっても、このレリックが付いたままなら積みは残る。レリックを合成したときだけ、積みの扱いは合成先のルールに従う。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 軽減 | 5 |
