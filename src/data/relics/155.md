# 観光

- ID: 155
- 名前: 観光
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

積みが増えるたびに、そのあとの1回ぶんの増え方が大きくなる。

## 詳細な説明文

このレリックを装備しているあいだ、このレリック以外の「ラウンドをまたぐ成長」のレリックが積みを増やすとき、増える量が、効果値の追加の欄の値だけ多い。2である。この欄は%である。自分自身の積みには入らない。ほかの成長レリックが同じキャラクターに付いているときに入る。追加ぶんも、そのレリックの積みとして残る。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 追加 | 2 |
