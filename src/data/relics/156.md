# ギター

- ID: 156
- 名前: ギター
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

同じキャラクターに付いた成長レリックの与ダメージ上昇を、1%につきゴールド2に換えられる。

## 詳細な説明文

このレリックを装備しているあいだ、任意のタイミングで、同じキャラクターに付いている「ラウンドをまたぐ成長」のレリックが蓄えてきた与ダメージ上昇を、すべてゴールドに換えられる。上昇1%につき、ゴールドが2入る。換えたあと、それらの与ダメージ上昇は0に戻る。最大体力や受けるダメージ軽減など、与ダメージ以外の上昇分は換えられない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 2 |
