# ギター

- ID: 156
- 名前: ギター
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

同じキャラクターの与ダメージの積みをゴールドに換えられる。

## 詳細な説明文

このレリックを装備しているあいだ、任意のタイミングで、同じキャラクターに付いている「ラウンドをまたぐ成長」のレリックの与ダメージの積みを、すべてゴールドに換えられる。積み1%につき、効果値のゴールドの欄の値だけ入る。2である。この欄は%ではない。換えた積みは0になる。それらの与ダメージの上昇も消える。最大体力や軽減など、与ダメージ以外の積みは換えられない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 2 |
