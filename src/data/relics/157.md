# 恐竜

- ID: 157
- 名前: 恐竜
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者が撃破するたび、プレイヤーHPが回復する。

## 詳細な説明文

このレリックを装備しているキャラクターが敵を撃破するたび、プレイヤーHPが回復する。1回の回復は、効果値のHPの欄の値である。2である。この欄は%ではない。1回の戦闘での回復の上限は、効果値の上限の欄の値である。8である。上限に達したあとは、その戦闘では回復しない。次の戦闘ではまた回復する。積みではないが、マッチのあいだずっと付いている。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| HP | 2 |
| 上限 | 8 |
