# クイズ

- ID: 158
- 名前: クイズ
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

マッチの経過ラウンドに応じて、装備者の与ダメージが高くなる。

## 詳細な説明文

このレリックを装備しているあいだ、いまのマッチの経過ラウンド数に、効果値の与ダメージの欄の値を掛けたぶんだけ、装備者の与ダメージが高くなる。与ダメージは3である。この欄は%である。ラウンド1なら3%、ラウンド10なら30%である。装備した時点のラウンドから数えるのではなく、マッチ全体のラウンド数である。外すと消える。積みではない。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 3 |
