# 軽薄

- ID: 159
- 名前: 軽薄
- 分類: ラウンドをまたぐ成長
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

連勝・連敗に応じて、毎ラウンドの与ダメージの積みが増える。

## 詳細な説明文

このレリックを装備しているあいだ、ラウンド開始時に、このレリックの与ダメージの積みが増える。連勝が1以上のとき、増える量は、効果値の連勝の欄の値である。8である。連敗が1以上のとき、増える量は、効果値の連敗の欄の値である。5である。この欄は%である。連勝と連敗が両方0のときは増えない。両方あることはないので、有効な連の方だけ入る。積んだぶんだけ、装備者の与ダメージが高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。積みは、このレリックに残る。付け替えても残る。キャラクターが同種合成や異種合成で別の体になっても、このレリックが付いたままなら積みは残る。レリックを合成したときだけ、積みの扱いは合成先のルールに従う。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 連勝 | 8 |
| 連敗 | 5 |
