# コマーシャル

- ID: 161
- 名前: コマーシャル
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者の最大体力が8高くなる。枚数ぶん足す。

## 詳細な説明文

このレリックを装備しているキャラクターの最大体力が8%高くなる。いまの体力も、増えた最大体力と同じだけ増える。外すと消える。同じレリックを複数持っているときは、枚数ぶん足す。1つだけ、にはしない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 最大体力 | 8 |
