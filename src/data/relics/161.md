# コマーシャル

- ID: 161
- 名前: コマーシャル
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者の最大体力が8%高くなる。1枚装備するごとに重ねる。

## 詳細な説明文

このレリックを装備しているキャラクターの最大体力が8%高くなる。いまの体力も、増えた最大体力と同じだけ増える。外すと消える。同じ装備者に複数付いているときは、1枚につき8%ずつ足す。2枚なら16%である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 最大体力 | 8 |
