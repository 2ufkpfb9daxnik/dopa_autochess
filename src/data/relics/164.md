# 就職

- ID: 164
- 名前: 就職
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者が、2秒ごとに最大体力の4%を回復する。1枚装備するごとに重ねる。

## 詳細な説明文

このレリックを装備しているキャラクターは、戦闘中、2行動ごとに最大体力の4%だけ体力が戻る。間隔は2である。秒である。最大体力は超えない。外すと消える。同じ装備者に複数付いているときは、1枚につき4%ずつ足す。2枚なら8%である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回復 | 4 |
| 間隔 | 2 |
