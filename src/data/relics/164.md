# 就職

- ID: 164
- 名前: 就職
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者が、最大体力の一部を定期的に回復する。枚数ぶん足す。

## 詳細な説明文

このレリックを装備しているキャラクターは、戦闘中、一定時間ごとに最大体力の4%だけ体力が戻る。間隔は2である。秒である。最大体力は超えない。外すと消える。同じレリックを複数持っているときは、枚数ぶん足す。1つだけ、にはしない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回復 | 4 |
| 間隔 | 2 |
