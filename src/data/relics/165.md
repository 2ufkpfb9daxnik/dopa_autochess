# 乗車拒否

- ID: 165
- 名前: 乗車拒否
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者が生存中、味方全員の受けるダメージが低くなる。枚数ぶん足す。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、味方全員が攻撃で受けるダメージが低くなる。装備者自身も入る。低くなる割合は、効果値の受けるダメージの欄の値である。3である。この欄は%である。継続ダメージにも入る。装備者の体力が0以下のときと、外したときに消える。同じレリックを複数持っているときは、枚数ぶん足す。1つだけ、にはしない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受けるダメージ | 3 |
