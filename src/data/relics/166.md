# 蒸発

- ID: 166
- 名前: 蒸発
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方が受けたダメージが一定割合たまるたび、同じレリックが1つ入る。

## 詳細な説明文

このレリックを1つ以上持っているあいだ、味方全員が受けたダメージの合計を覚える。合計が、味方の最大体力の合計のうち、効果値の閾値の欄の割合に達するたび、同じレリックが1つ手元に入る。閾値は25である。この欄は%である。達するたびに、覚えた合計からそのぶんを引く。何回でも入る。上限はない。このレリック自体の枚数が増えても、閾値の計算は変えない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 閾値 | 25 |
