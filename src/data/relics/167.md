# 西部劇

- ID: 167
- 名前: 西部劇
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者が倒れたとき、同じレリックが別の味方に付く。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0以下になったとき、同じレリックが1つ、体力が0より大きい別の味方に付く。付く先は、前衛を優先し、いなければ後衛から無作為である。すでにこのレリックを付けているキャラクターにも付いてよい。枚数ぶん足す効果なら、そのまま足す。付ける先がいないときは手元に入る。元のレリックは装備者から外れて消えない。手元か、付いた先に残る。1回の戦闘で、この乗り移りは、効果値の回数の欄の値までである。2である。この欄は%ではない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回数 | 2 |
