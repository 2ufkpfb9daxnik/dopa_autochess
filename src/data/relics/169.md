# 騒音

- ID: 169
- 名前: 騒音
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

ラウンド開始時、しばしば同じレリックがもう1つ入る。

## 詳細な説明文

このレリックを1つ以上持っているあいだ、ラウンド開始時に、同じレリックがもう1つ手元に入ることがある。入るのは、合計10回のうち、4である。持っている枚数に関係なく、判定は1回である。当たれば1つ入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 当たり | 4 |
