# サンデイ

- ID: 172
- 名前: サンデイ
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: いいえ
- 合成可能: はい

## 簡単な説明文

負けたあと、プレイヤーHPが、欠け分の一部回復する。枚数で割合が増える。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤー同士の戦闘に負けたあと、プレイヤーHPが戻る。戻る量は、欠けているプレイヤーHPのうち、効果値の回復の欄の割合である。8である。この欄は%である。枚数ぶん足す。2枚なら16%である。勝ったときと引き分けのときは入らない。キャラクターに装備しなくても入る。同じレリックを複数持っているときは、枚数ぶん足す。1つだけ、にはしない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回復 | 8 |
