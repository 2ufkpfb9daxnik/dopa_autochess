# サンデイ

- ID: 172
- 名前: サンデイ
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: いいえ
- 合成可能: はい

## 簡単な説明文

負けたあと、プレイヤーHPの欠け分の8%が回復する。1枚持っているごとに重ねる。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤー同士の戦闘に負けたあと、プレイヤーHPが戻る。戻る量は、欠けているプレイヤーHPのうち8%である。手元に複数あるときは、1枚につき8%ずつ足す。2枚なら16%である。勝ったときと引き分けのときは入らない。キャラクターに装備しなくても入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回復 | 8 |
