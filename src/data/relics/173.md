# 法螺話

- ID: 173
- 名前: 法螺話
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者の余剰回復がシールドになる。上限は最大体力の20%。1枚装備するごとに上限が重なる。

## 詳細な説明文

このレリックを装備しているキャラクターが、最大体力を超えて回復しようとしたとき、超えたぶんがシールドになる。シールドの上限は、最大体力のうち20%である。同じ装備者に複数付いているときは、1枚につき上限20%ずつ足す。2枚なら上限40%である。シールドは戦闘が終わると消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| シールド | 20 |
