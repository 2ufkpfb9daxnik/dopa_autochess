# 法螺話

- ID: 173
- 名前: 法螺話
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者の余剰回復がシールドになる。枚数で上限が足される。

## 詳細な説明文

このレリックを装備しているキャラクターが、最大体力を超えて回復しようとしたとき、超えたぶんがシールドになる。シールドの上限は、最大体力のうち、効果値のシールドの欄の割合である。20である。この欄は%である。枚数ぶん足す。2枚なら上限40%である。シールドは戦闘が終わると消える。同じレリックを複数持っているときは、枚数ぶん足す。1つだけ、にはしない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| シールド | 20 |
