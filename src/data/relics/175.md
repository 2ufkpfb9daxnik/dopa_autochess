# 末世

- ID: 175
- 名前: 末世
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

戦闘開始時、最大体力の15%のシールドを得る。1枚装備するごとに重ねる。

## 詳細な説明文

このレリックを装備しているキャラクターは、戦闘開始時にシールドを得る。量は、最大体力のうち15%である。同じ装備者に複数付いているときは、1枚につき15%ずつ足す。2枚なら30%である。シールドは戦闘が終わると消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| シールド | 15 |
