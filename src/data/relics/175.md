# 末世

- ID: 175
- 名前: 末世
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

戦闘開始時、最大体力の一部のシールドを得る。枚数ぶん足す。

## 詳細な説明文

このレリックを装備しているキャラクターは、戦闘開始時にシールドを得る。量は、最大体力のうち、効果値のシールドの欄の割合である。15である。この欄は%である。枚数ぶん足す。シールドは戦闘が終わると消える。同じレリックを複数持っているときは、枚数ぶん足す。1つだけ、にはしない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| シールド | 15 |
