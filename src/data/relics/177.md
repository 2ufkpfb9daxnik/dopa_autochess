# よろめき

- ID: 177
- 名前: よろめき
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

攻撃を受けるたび、その戦闘中だけ受けるダメージが2%低くなる。1枚装備するごとに、開始時からそのぶん厚くなる。

## 詳細な説明文

このレリックを装備しているキャラクターが攻撃を受けるたび、その戦闘のあいだだけ、受けるダメージが低くなる積みが増える。1回で増える割合は2%である。同じ装備者に複数付いているときは、戦闘開始時に1枚につき2%ずつあらかじめ積む。2枚なら、開始時にすでに4%低い。継続ダメージの被弾でも増える。戦闘が終わると積みは消える。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受けるダメージ | 2 |
