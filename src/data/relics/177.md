# よろめき

- ID: 177
- 名前: よろめき
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

攻撃を受けるたび、その戦闘中だけ受けるダメージが低くなる。枚数で初回から厚い。

## 詳細な説明文

このレリックを装備しているキャラクターが攻撃を受けるたび、その戦闘のあいだだけ、受けるダメージが低くなる積みが増える。1回で増える割合は、効果値の受けるダメージの欄の値である。2である。この欄は%である。枚数ぶん、戦闘開始時にあらかじめ同じ積みを持つ。2枚なら、開始時にすでに4%低い。継続ダメージの被弾でも増える。戦闘が終わると積みは消える。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受けるダメージ | 2 |
