# 落語

- ID: 178
- 名前: 落語
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

キャラクターを合成したとき、同じレリックが1つ入る。回数制限あり。

## 詳細な説明文

このレリックを1つ以上持っているあいだ、同種合成でも異種合成でも、合成したときに同じレリックが1つ手元に入る。入るたびに残り回数を1減らす。残り回数の最初は、効果値の回数の欄の値である。4である。この欄は%ではない。残り回数が0になると、この増殖は起きない。このレリック自体は残る。持っている枚数に関係なく、1回の合成につき追加は1つである。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回数 | 4 |
