# レジャー

- ID: 180
- 名前: レジャー
- 分類: (プレイヤーもキャラクターも)HP、防御の増強、回復
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

このレリック1枚を消すと、弱い耐久レリックが2つ入る。

## 詳細な説明文

このレリックを1つ消費すると、最大体力が高くなるレリック（コマーシャルと同効果）が2つ手元に入る。入る2つは、効果値の最大体力の欄の値が、このレジャーより小さい。5である。この欄は%である。コマーシャル本体ではなく、この効果で入った複製である。枚数加算の対象になる。マッチ中、消費できる回数は、効果値の回数の欄の値までである。2である。この欄は%ではない。使い切っても、まだ持っているレジャーがあれば残る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 最大体力 | 5 |
| 回数 | 2 |
