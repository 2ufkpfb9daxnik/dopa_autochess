# 論争

- ID: 181
- 名前: 論争
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

前衛の空きに、攻撃を受ける装置を1つ置く。

## 詳細な説明文

このレリックを持っているあいだ、戦闘開始時に前衛の空き枠が1つ以上あるとき、そのうちの1枠に装置を置く。装置は攻撃の対象になる。受け皿は、戦闘開始時の味方全員の最大体力の合計のうち40%である。受け皿が0になると装置は壊れて消える。装置は攻撃しない。出撃上限の人数には入る。装置はキャラクターではない。新しいモデルは使わない。シナジーの人数には入らない。ビアンカ・オーバースタディの召喚物とは別である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受け皿 | 40 |
