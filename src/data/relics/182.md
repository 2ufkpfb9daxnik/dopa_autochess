# 肋骨

- ID: 182
- 名前: 肋骨
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

攻撃を受ける装置を2つまで置く。戦闘開始時、敵の最初の攻撃を装置が受ける。

## 詳細な説明文

このレリックを持っているあいだ、戦闘開始時に前衛の空き枠へ、攻撃を受ける装置を最大2つ置く。1つあたりの受け皿は、味方全員の最大体力の合計のうち25%である。戦闘開始直後の、敵の最初の攻撃1回は、必ず装置のうち1つが受ける。装置が無いときは通常どおりである。出撃上限の人数には、置いた装置の数だけ入る。装置はキャラクターではない。新しいモデルは使わない。シナジーの人数には入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受け皿 | 25 |
