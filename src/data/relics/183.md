# 横車

- ID: 183
- 名前: 横車
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

攻撃を受ける装置が壊れるたび、ゴールドが入る。

## 詳細な説明文

このレリックを持っているあいだ、攻撃を受ける装置が壊れたとき、ゴールドが入る。入る量は、効果値のゴールドの欄の値である。1である。この欄は%ではない。1回の戦闘で入る回数は、効果値の上限の欄の値までである。3である。装置を置く効果は、このレリック単体では持たない。論争や肋骨などと一緒に持つ。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 1 |
| 上限 | 3 |
