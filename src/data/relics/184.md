# 不調和

- ID: 184
- 名前: 不調和
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装置が何度か壊れたら、耐久レリックが1つ入って消える。

## 詳細な説明文

このレリックを持っているあいだ、攻撃を受ける装置が壊れるたびに回数を1数える。回数が8に達したとき、分類が「(プレイヤーもキャラクターも)HP、防御の増強、回復」のレリックが1つ、無作為に手元に入る。回数は8である。入ったあと、このレリックは消える。装置を置く効果は、このレリック単体では持たない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 回数 | 8 |
