# アップルパイ

- ID: 187
- 名前: アップルパイ
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

戦闘開始時、控えのキャラクター1体のコピーが1戦闘だけ出る。

## 詳細な説明文

このレリックを持っているあいだ、戦闘開始時に控えにキャラクターが1体以上いるとき、無作為な1体と同じキャラクター・同じ星のコピーが、空き枠に1体出る。コピーの与ダメージは50%だけ低い。50である。コピーはレリックを持たない。シナジーの人数には入らない。出撃上限の人数には入る。見た目は元のキャラクターと同じである。新しいモデルは使わない。戦闘が終わると消える。控えが空のときと、空き枠が無いときは出ない。壁の召喚はしない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 50 |
