# ピアノ

- ID: 188
- 名前: ピアノ
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

戦闘開始時、装備者のコピーが1戦闘だけ出る。

## 詳細な説明文

このレリックを装備しているキャラクターがサークルにいるとき、戦闘開始時に、同じキャラクター・同じ星のコピーが空き枠に1体出る。コピーの与ダメージは50%だけ低い。50である。コピーはレリックを持たない。シナジーの人数には入らない。出撃上限の人数には入る。見た目は装備者と同じである。戦闘が終わると消える。空き枠が無いときは出ない。装備者が控えにいるときは出ない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 50 |
