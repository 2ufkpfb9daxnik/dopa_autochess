# 客

- ID: 189
- 名前: 客
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方の召喚物の最大体力と与ダメージが、どちらも20%高くなる。

## 詳細な説明文

このレリックを持っているあいだ、味方の召喚物の最大体力と与ダメージがどちらも20%高くなる。ビアンカ・オーバースタディの召喚物、サクライやユアサなどの一瞬の召喚、サノの残す召喚、この分類のコピーも入る。装置には入らない。キャラクター本体には入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 最大体力 | 20 |
| 与ダメージ | 20 |
