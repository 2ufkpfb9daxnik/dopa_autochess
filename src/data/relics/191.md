# 見学

- ID: 191
- 名前: 見学
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

控えに卵枠がある。入れたキャラクターが、数ラウンドで星が上がって戻る。

## 詳細な説明文

このレリックを持っているあいだ、控えに卵枠が1つできる。キャラクターを1体入れると、4ラウンド数のあいだ、卵の中にいる。ラウンドは4である。終わると、同じキャラクターが、星が1段高い状態で控えに戻る。★4のときは星はそのままで戻る。途中で卵を売ると、入れたときと同じ星で戻る。卵に入れているあいだは出撃できない。新しいモデルは使わない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ラウンド | 4 |
