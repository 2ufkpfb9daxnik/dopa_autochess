# 帰宅

- ID: 192
- 名前: 帰宅
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

数ラウンド後に、ゴールドとレリックが入る。勝つと1ラウンド早い。

## 詳細な説明文

このレリックを入手したときから、効果値のラウンドの欄の値のラウンド数が減っていく。ラウンドは8である。この欄は%ではない。プレイヤー同士の戦闘に勝つたび、残りがさらに1減る。残りが0になったとき、ゴールドが、効果値のゴールドの欄の値だけ入り、レリックが1つ無作為に手元に入る。ゴールドは15である。入ったあと、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ラウンド | 8 |
| ゴールド | 15 |
