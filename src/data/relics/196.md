# 凶暴

- ID: 196
- 名前: 凶暴
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者が倒れたとき、1回だけ攻撃して消える。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0以下になったとき、その位置から敵1体へ攻撃が1回出る。攻撃力は装備者の、倒れる直前の攻撃力である。属性は装備者の攻撃属性である。与ダメージは、効果値の与ダメージの欄の割合だけ高い。25である。この欄は%である。対象は、装備者を倒した敵である。いなければ、前衛の生きている敵のうちIDが小さい1体である。席には残らない。シナジーの人数には入らない。ビアンカの召喚物とは別である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 25 |
