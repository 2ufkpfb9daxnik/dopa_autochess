# 年賀状

- ID: 198
- 名前: 年賀状
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

ラウンド開始時、攻撃を受ける装置が無ければ1つ置く。

## 詳細な説明文

このレリックを持っているあいだ、ラウンド開始時に、攻撃を受ける装置が1つも無ければ、論争と同じ装置を1つ置く。受け皿は、味方全員の最大体力の合計のうち、効果値の受け皿の欄の割合である。40である。この欄は%である。前衛に空きが無いときは置かない。すでに装置があるときは置かない。装置はキャラクターではない。新しいモデルは使わない。シナジーの人数には入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受け皿 | 40 |
