# 地震

- ID: 199
- 名前: 地震
- 分類: 召喚物・盤面装置
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

置いている装置の数だけ、味方全員の受けるダメージが低い。

## 詳細な説明文

このレリックを持っているあいだ、いまの戦闘に置いている装置1つにつき、味方全員が攻撃で受けるダメージが低くなる。1つあたりの割合は3%である。攻撃を受ける装置も、攻撃されない装置も数える。コピーや召喚物は数えない。継続ダメージにも入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受けるダメージ | 3 |
