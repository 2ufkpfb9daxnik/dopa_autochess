# シネクドキ

- ID: 201
- 名前: シネクドキ
- 分類: シナジー追加
- 追加シナジー: にぎやかな未来
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、にぎやかな未来に入る。炎属性の攻撃が少し強くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、にぎやかな未来のシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターの炎属性の攻撃が与えるダメージが高くなる。高くなる割合は、効果値の炎の与ダメージの欄の値である。8%である。通常の攻撃、その範囲ダメージ、炎の継続ダメージに入る。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 炎の与ダメージ | 8 |
