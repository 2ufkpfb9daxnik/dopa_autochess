# シネクドキ

- ID: 201
- 名前: シネクドキ
- 分類: シナジー追加
- 追加シナジー: にぎやかな未来
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがにぎやかな未来のシナジーに所属する。炎属性の攻撃が少し強くなる。

## 詳細な説明文

装備したキャラクターはにぎやかな未来のシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでににぎやかな未来のシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの炎属性の攻撃が与えるダメージが8%高くなる。通常の攻撃、その範囲ダメージ、炎の継続ダメージに入る。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 炎の与ダメージ | 8 |
