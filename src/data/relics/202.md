# モーツァルト

- ID: 202
- 名前: モーツァルト
- 分類: シナジー追加
- 追加シナジー: わたしのグランパ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがわたしのグランパのシナジーに所属する。最大体力が12高くなる。

## 詳細な説明文

装備したキャラクターはわたしのグランパのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにわたしのグランパのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの最大体力が12高くなる。いまの体力も、同じ量だけ高くなる。新しい最大体力は超えない。外すと消える。いまの体力は、新しい最大体力を超えない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 最大体力 | 12 |
