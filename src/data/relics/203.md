# 冬にして君を離れ

- ID: 203
- 名前: 冬にして君を離れ
- 分類: シナジー追加
- 追加シナジー: アンジップ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがアンジップのシナジーに所属する。氷属性の攻撃が少し強くなる。

## 詳細な説明文

装備したキャラクターはアンジップのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにアンジップのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの氷属性の攻撃が与えるダメージが8%高くなる。通常の攻撃、その範囲ダメージ、氷の継続ダメージに入る。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 氷の与ダメージ | 8 |
