# 横丁

- ID: 206
- 名前: 横丁
- 分類: シナジー追加
- 追加シナジー: ギプノーザ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがギプノーザのシナジーに所属する。受けるダメージが5%低くなる。

## 詳細な説明文

装備したキャラクターはギプノーザのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにギプノーザのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターが攻撃で受けるダメージが5%低くなる。継続ダメージには入らない。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受けるダメージ | 5 |
