# 七曲り

- ID: 207
- 名前: 七曲り
- 分類: シナジー追加
- 追加シナジー: ジャックポット
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、ジャックポットに入る。ゴールドが少し入る。

## 詳細な説明文

このレリックを装備しているキャラクターは、ジャックポットのシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

このレリックを装備しているキャラクターがサークルに乗っているラウンドの開始時、ゴールドが入る。入る量は、効果値のゴールドの欄の値である。1である。この欄は%ではない。控えにいるラウンドでは入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 1 |
