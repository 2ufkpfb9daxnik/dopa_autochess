# 七曲り

- ID: 207
- 名前: 七曲り
- 分類: シナジー追加
- 追加シナジー: ジャックポット
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがジャックポットのシナジーに所属する。ゴールドが少し入る。

## 詳細な説明文

装備したキャラクターはジャックポットのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにジャックポットのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

このレリックを装備しているキャラクターがサークルに乗っているラウンドの開始時、ゴールドが1入る。控えにいるラウンドでは入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 1 |
