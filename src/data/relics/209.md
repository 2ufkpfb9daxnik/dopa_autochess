# 讃歌

- ID: 209
- 名前: 讃歌
- 分類: シナジー追加
- 追加シナジー: スキューバ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがスキューバのシナジーに所属する。経験値が少し入る。

## 詳細な説明文

装備したキャラクターはスキューバのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにスキューバのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

このレリックを装備しているキャラクターがサークルに乗っているラウンドの終了時、経験値が1入る。控えにいるラウンドでは入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 経験値 | 1 |
