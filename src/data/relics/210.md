# 芝生

- ID: 210
- 名前: 芝生
- 分類: シナジー追加
- 追加シナジー: ソア橋
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがソア橋のシナジーに所属する。土属性の攻撃が少し強くなる。

## 詳細な説明文

装備したキャラクターはソア橋のシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにソア橋のシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの土属性の攻撃が与えるダメージが8%高くなる。通常の攻撃、その範囲ダメージ、土の継続ダメージに入る。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 土の与ダメージ | 8 |
