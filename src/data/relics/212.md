# 画家

- ID: 212
- 名前: 画家
- 分類: シナジー追加
- 追加シナジー: ナギナタスタイル
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、ナギナタスタイルに入る。攻撃力が高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、ナギナタスタイルのシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターの攻撃力が高くなる。高くなる量は、効果値の攻撃力の欄の値である。12である。この欄は%ではない。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 攻撃力 | 12 |
