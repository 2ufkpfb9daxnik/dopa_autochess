# 画家

- ID: 212
- 名前: 画家
- 分類: シナジー追加
- 追加シナジー: ナギナタスタイル
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがナギナタスタイルのシナジーに所属する。攻撃力が高くなる。

## 詳細な説明文

装備したキャラクターはナギナタスタイルのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにナギナタスタイルのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの攻撃力が12高くなる。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 攻撃力 | 12 |
