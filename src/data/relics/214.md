# ワイド

- ID: 214
- 名前: ワイド
- 分類: シナジー追加
- 追加シナジー: パンドラ・オートロード
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、パンドラ・オートロードに入る。クリティカル率が高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、パンドラ・オートロードのシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターのクリティカル率が高くなる。高くなる量は、効果値のクリティカル率の欄の値である。8である。この欄は%ではない。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| クリティカル率 | 8 |
