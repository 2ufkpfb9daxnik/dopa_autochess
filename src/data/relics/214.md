# ワイド

- ID: 214
- 名前: ワイド
- 分類: シナジー追加
- 追加シナジー: パンドラ・オートロード
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがパンドラ・オートロードのシナジーに所属する。クリティカル率が8高くなる。

## 詳細な説明文

装備したキャラクターはパンドラ・オートロードのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにパンドラ・オートロードのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターのクリティカル率が8高くなる。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| クリティカル率 | 8 |
