# 反映

- ID: 217
- 名前: 反映
- 分類: シナジー追加
- 追加シナジー: ポップミュージック
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、ポップミュージックに入る。ゲージが増えやすい。

## 詳細な説明文

このレリックを装備しているキャラクターは、ポップミュージックのシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターのゲージが増える量が高くなる。高くなる割合は、効果値のゲージの欄の値である。15%である。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゲージ | 15 |
