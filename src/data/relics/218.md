# 年譜

- ID: 218
- 名前: 年譜
- 分類: シナジー追加
- 追加シナジー: ポプリ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがポプリのシナジーに所属する。防御力が20高くなる。

## 詳細な説明文

装備したキャラクターはポプリのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにポプリのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの防御力が20高くなる。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 防御力 | 20 |
