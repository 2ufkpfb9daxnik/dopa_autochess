# 年譜

- ID: 218
- 名前: 年譜
- 分類: シナジー追加
- 追加シナジー: ポプリ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、ポプリに入る。防御力が高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、ポプリのシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターの防御力が高くなる。高くなる量は、効果値の防御力の欄の値である。20である。この欄は%ではない。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 防御力 | 20 |
