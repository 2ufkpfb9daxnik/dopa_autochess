# スター

- ID: 220
- 名前: スター
- 分類: シナジー追加
- 追加シナジー: メタモルフォセス群島
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがメタモルフォセス群島のシナジーに所属する。与ダメージが8%高くなる。

## 詳細な説明文

装備したキャラクターはメタモルフォセス群島のシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにメタモルフォセス群島のシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの与ダメージが8%高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 8 |
