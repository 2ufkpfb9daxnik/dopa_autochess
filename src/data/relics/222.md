# 狂乱時代

- ID: 222
- 名前: 狂乱時代
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがモンスターのシナジーに所属する。最初の攻撃が強くなる。

## 詳細な説明文

装備したキャラクターはモンスターのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにモンスターのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの、その戦闘での最初の通常の攻撃の与ダメージが15%高くなる。通常の攻撃と、その範囲ダメージに入る。継続ダメージには入らない。最初の通常の攻撃をしたら、外れても終わる。外しても消える。
