# 狂乱時代

- ID: 222
- 名前: 狂乱時代
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、モンスターに入る。最初の攻撃が強くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、モンスターのシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターの、その戦闘での最初の通常の攻撃の与ダメージが高くなる。高くなる割合は、効果値の最初の与ダメージの欄の値である。15%である。通常の攻撃と、その範囲ダメージに入る。継続ダメージには入らない。最初の通常の攻撃をしたら、外れても終わる。外しても消える。
