# 迎賓館

- ID: 224
- 名前: 迎賓館
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがヨッパ谷への降下のシナジーに所属する。氷属性の攻撃が少し強くなる。

## 詳細な説明文

装備したキャラクターはヨッパ谷への降下のシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにヨッパ谷への降下のシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの氷属性の攻撃が与えるダメージが8%高くなる。通常の攻撃、その範囲ダメージ、氷の継続ダメージに入る。外しても消える。
