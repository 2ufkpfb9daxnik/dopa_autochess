# 超能力

- ID: 228
- 名前: 超能力
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターが新しい下駄を履くのシナジーに所属する。最大体力が12高くなる。

## 詳細な説明文

装備したキャラクターは新しい下駄を履くのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでに新しい下駄を履くのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの最大体力が12高くなる。いまの体力も、同じ量だけ高くなる。新しい最大体力は超えない。外すと消える。いまの体力は、新しい最大体力を超えない。外しても消える。
