# 超能力

- ID: 228
- 名前: 超能力
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、新しい下駄を履くに入る。最大体力が高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、新しい下駄を履くのシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターの最大体力が高くなる。いまの体力も、同じ量だけ高くなる。新しい最大体力は超えない。高くなる量は、効果値の最大体力の欄の値である。12である。この欄は%ではない。外すと消える。いまの体力は、新しい最大体力を超えない。外しても消える。
