# 青春

- ID: 230
- 名前: 青春
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターが時をかける少女のシナジーに所属する。速度が12高くなる。

## 詳細な説明文

装備したキャラクターは時をかける少女のシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでに時をかける少女のシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの速度が12高くなる。行動の間隔は、その速度で決まる。いま残っている行動ポイントは変わらない。外しても消える。
