# 記憶

- ID: 231
- 名前: 記憶
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、月2-263に入る。受けるダメージが低くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、月2-263のシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターが攻撃で受けるダメージが低くなる。低くなる割合は、効果値の受けるダメージの欄の値である。5%である。継続ダメージには入らない。外しても消える。
