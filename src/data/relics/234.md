# 怪奇

- ID: 234
- 名前: 怪奇
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、東雲に入る。水属性の攻撃が少し強くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、東雲のシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターの水属性の攻撃が与えるダメージが高くなる。高くなる割合は、効果値の水の与ダメージの欄の値である。8%である。通常の攻撃、その範囲ダメージ、水の継続ダメージに入る。外しても消える。
