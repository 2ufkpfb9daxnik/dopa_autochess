# 星屑

- ID: 235
- 名前: 星屑
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターが狂気の沙汰も金次第のシナジーに所属する。土属性の攻撃が少し強くなる。

## 詳細な説明文

装備したキャラクターは狂気の沙汰も金次第のシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでに狂気の沙汰も金次第のシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの土属性の攻撃が与えるダメージが8%高くなる。通常の攻撃、その範囲ダメージ、土の継続ダメージに入る。外しても消える。
