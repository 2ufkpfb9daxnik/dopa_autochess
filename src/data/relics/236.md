# アイスクリーム

- ID: 236
- 名前: アイスクリーム
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、笑うなに入る。クリティカル率が高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、笑うなのシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターのクリティカル率が高くなる。高くなる量は、効果値のクリティカル率の欄の値である。6である。この欄は%ではない。シートのクリティカル率に、この値が入る。外しても消える。
