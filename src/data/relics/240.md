# メイド

- ID: 240
- 名前: メイド
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、カーテンコールに入る。吸収属性の攻撃が少し強くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、カーテンコールのシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターの吸収属性の攻撃が与えるダメージが高くなる。高くなる割合は、効果値の吸収の与ダメージの欄の値である。8%である。通常の攻撃、その範囲ダメージ、吸収の継続ダメージに入る。外しても消える。
