# モダン

- ID: 241
- 名前: モダン
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、ギリシャ語通訳に入る。速度が高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、ギリシャ語通訳のシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターの速度が高くなる。高くなる量は、効果値の速度の欄の値である。8である。この欄は%ではない。行動の間隔は、その速度で決まる。いま残っている行動ポイントは変わらない。外しても消える。
