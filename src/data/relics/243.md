# 街

- ID: 243
- 名前: 街
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがハイブリッド月のシナジーに所属する。防御力が15高くなる。

## 詳細な説明文

装備したキャラクターはハイブリッド月のシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにハイブリッド月のシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの防御力が15高くなる。外しても消える。
