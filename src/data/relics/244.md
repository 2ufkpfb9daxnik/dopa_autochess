# 突撃

- ID: 244
- 名前: 突撃
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターがビストロンのシナジーに所属する。与ダメージが6%高くなる。

## 詳細な説明文

装備したキャラクターはビストロンのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでにビストロンのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの与ダメージが6%高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。外しても消える。
