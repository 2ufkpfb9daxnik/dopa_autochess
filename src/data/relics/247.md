# 函数

- ID: 247
- 名前: 函数
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターが四つの署名のシナジーに所属する。クリティカル率が8高くなる。

## 詳細な説明文

装備したキャラクターは四つの署名のシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでに四つの署名のシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターのクリティカル率が8高くなる。シートのクリティカル率に、この値が入る。外しても消える。
