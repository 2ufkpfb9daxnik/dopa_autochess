# ビタミン

- ID: 248
- 名前: ビタミン
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、家族八景に入る。後衛にいるとき、与ダメージが高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、家族八景のシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターが後衛にいるあいだ、与ダメージが高くなる。高くなる割合は、効果値の与ダメージの欄の値である。10%である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。前衛にいるときは入らない。外しても消える。
