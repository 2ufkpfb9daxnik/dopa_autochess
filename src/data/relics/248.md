# ビタミン

- ID: 248
- 名前: ビタミン
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターが家族八景のシナジーに所属する。後衛にいるとき、与ダメージが10%高くなる。

## 詳細な説明文

装備したキャラクターは家族八景のシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでに家族八景のシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターが後衛にいるあいだ、与ダメージが10%高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。前衛にいるときは入らない。外しても消える。
