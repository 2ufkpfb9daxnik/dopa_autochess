# 祭り

- ID: 249
- 名前: 祭り
- 分類: シナジー追加
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターが敵のシナジーに所属する。攻撃力が高くなる。

## 詳細な説明文

装備したキャラクターは敵のシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでに敵のシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの攻撃力が8高くなる。継続ダメージの攻撃力にも入る。外しても消える。
