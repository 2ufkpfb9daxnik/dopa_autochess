# 

- ID: 252
- 名前: 
- 分類: シナジー追加
- 追加シナジー: 農協月へ行く
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備したキャラクターが農協月へ行くのシナジーに所属する。風属性の攻撃が少し強くなる。

## 詳細な説明文

装備したキャラクターは農協月へ行くのシナジーに所属する。サークルに乗せていて、体力が0より大きいあいだ所属する。すでに農協月へ行くのシナジーに所属しているキャラクターには装備できない。控えにいるあいだは所属しない。外すと消える。

装備しているキャラクターの風属性の攻撃が与えるダメージが8%高くなる。通常の攻撃、その範囲ダメージ、風の継続ダメージに入る。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 風の与ダメージ | 8 |
