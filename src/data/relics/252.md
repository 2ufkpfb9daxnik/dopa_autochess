# 

- ID: 252
- 名前: 
- 分類: シナジー追加
- 追加シナジー: 農協月へ行く
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備すると、農協月へ行くに入る。風属性の攻撃が少し強くなる。

## 詳細な説明文

このレリックを装備しているキャラクターは、農協月へ行くのシナジーに入る。サークルに乗せていて、体力が0より大きいあいだ入る。もともと入っているときは、人数は増えない。控えにいるあいだは入らない。外すと消える。

装備しているキャラクターの風属性の攻撃が与えるダメージが高くなる。高くなる割合は、効果値の風の与ダメージの欄の値である。8%である。通常の攻撃、その範囲ダメージ、風の継続ダメージに入る。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 風の与ダメージ | 8 |
