# 二重

- ID: 254
- 名前: 二重
- 分類: 強い利益と明確な代償
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

経験値購入をプレイヤーHPでしか払えなくなる。その代わり、毎ラウンド経験値が多く入る。

## 詳細な説明文

このレリックを持っているあいだ、経験値をゴールドで買うことはできない。経験値購入は、プレイヤーHPだけで払う。1回あたりの支払いは、効果値のHPの欄の値である。4である。この欄は%ではない。入る経験値は、基本の4に、効果値の経験値の欄の値を足した数である。追加は2である。つまり1回で6である。さらに、ラウンド開始時に経験値が、効果値の毎ラウンドの欄の値だけ入る。3である。小群とは別である。両方あるときは、ゴールド購入はやはりできない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| HP | 4 |
| 経験値 | 2 |
| 毎ラウンド | 3 |
