# フィックス

- ID: 255
- 名前: フィックス
- 分類: 強い利益と明確な代償
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

利息が入らなくなる。その代わり、毎ラウンドゴールドが多く入る。

## 詳細な説明文

このレリックを持っているあいだ、戦闘終了時の利息は入らない。ラウンド開始時に、ゴールドが5だけ入る。5である。入手時にも、同じ量のゴールドが1回入る。馬蹄や風力の利息効果は、利息自体が入らないので働かない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 5 |
