# 仇討ち

- ID: 256
- 名前: 仇討ち
- 分類: 強い利益と明確な代償
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方全員の与ダメージが大きく高い。最大体力は大きく低い。

## 詳細な説明文

このレリックを持っているあいだ、味方全員の与ダメージが25%高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。かわりに、味方全員の最大体力が20%低くなる。いまの体力も、減った最大体力に合わせて減る。最大体力の1は残る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 25 |
| 最大体力 | 20 |
