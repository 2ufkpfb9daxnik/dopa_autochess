# 絵画

- ID: 259
- 名前: 絵画
- 分類: 強い利益と明確な代償
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

連勝中だけ味方全員が非常に強い。連が途切れると、このレリックは消える。

## 詳細な説明文

このレリックを持っているあいだ、連勝が1以上のとき、味方全員の与ダメージが高くなり、受けるダメージが低くなる。与ダメージは、効果値の与ダメージの欄の値である。20である。受けるダメージは、効果値の受けるダメージの欄の値である。15である。この欄は%である。連勝が0になったとき、つまり連勝が途切れたとき、このレリックは消える。入手時に連勝が0なら、次に連勝が1以上になるまで効果は入らず、消えない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 20 |
| 受けるダメージ | 15 |
