# レコード

- ID: 260
- 名前: レコード
- 分類: 強い利益と明確な代償
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

プレイヤー最大HPが大きく増える。ショップに並ぶ高コストが出にくくなる。

## 詳細な説明文

このレリックを持っているあいだ、プレイヤーの最大HPが40%高くなる。いまのプレイヤーHPも、増えた最大HPと同じだけ増える。かわりに、ショップの出現率は、プレイヤーレベルが2である。レベルが1未満にはならない。ラジオや通過のレベル+1より、この低下を先に足し引きする。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 最大HP | 40 |
| レベル低下 | 2 |
