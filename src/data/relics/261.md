# ヴァリアント

- ID: 261
- 名前: ヴァリアント
- 分類: 強い利益と明確な代償
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

入手時にプレイヤーHPを大きく失う。そのあと数戦闘で、まとまったゴールドが入って消える。

## 詳細な説明文

このレリックを入手したとき、プレイヤーHPが、効果値のHPの欄の値だけ減る。20である。この欄は%ではない。減った結果が1未満のときは1である。そのあと、プレイヤー同士の戦闘が、効果値の戦闘の欄の値回終わるたびに数える。戦闘は7である。7回に達したとき、ゴールドが、効果値のゴールドの欄の値だけ入る。30である。入ったあと、このレリックは消える。途中で外しても、数えた戦闘回数はレリックに残る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| HP | 20 |
| 戦闘 | 7 |
| ゴールド | 30 |
