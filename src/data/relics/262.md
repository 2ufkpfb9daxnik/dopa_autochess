# タプル

- ID: 262
- 名前: タプル
- 分類: 強い利益と明確な代償
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

後衛の与ダメージが大きく高い。後衛は戦闘開始時の体力が低い。

## 詳細な説明文

このレリックを持っているあいだ、戦闘開始時に後衛にいる味方の与ダメージが高くなる。高くなる割合は、効果値の与ダメージの欄の値である。35である。この欄は%である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。かわりに、その味方は戦闘開始時の体力が、最大体力のうち、効果値の開始体力の欄の割合になる。60である。前衛には入らない。仇討ちの全体の体力低下とは別である。両方あるときは両方入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 35 |
| 開始体力 | 60 |
