# 構造

- ID: 263
- 名前: 構造
- 分類: 強い利益と明確な代償
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

入手時にゴールドをすべて失う。数ラウンド後に、失った分より多く戻って消える。

## 詳細な説明文

このレリックを入手したとき、所持ゴールドをすべて失う。失った量を覚える。5ラウンド数が経ったとき、覚えた量に、25を足したゴールドが入る。ラウンドは5である。追加は25である。入ったあと、このレリックは消える。入手時の所持が0のときも、5ラウンド後に追加の25だけ入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ラウンド | 5 |
| 追加 | 25 |
