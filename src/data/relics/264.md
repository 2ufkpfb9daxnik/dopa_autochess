# 特質

- ID: 264
- 名前: 特質
- 分類: 強い利益と明確な代償
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

合成上限が大きく高い。異種合成するたび、プレイヤーHPが減る。

## 詳細な説明文

このレリックを持っているあいだ、異種合成の合成上限が、効果値の上限の欄の値だけ高い。3である。この欄は%ではない。自動起動や雨粒とは別である。両方あるときは両方入る。かわりに、異種合成するたびに、プレイヤーHPが、効果値のHPの欄の値だけ減る。3である。減った結果が1未満のときは1である。同種合成では減らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 上限 | 3 |
| HP | 3 |
