# 散策

- ID: 265
- 名前: 散策
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

クリティカル率とクリティカルダメージが大きく高い。

## 詳細な説明文

このレリックを装備しているキャラクターのクリティカル率が高くなる。高くなる量は、効果値のクリティカル率の欄の値である。35である。この欄は%ではない。クリティカルダメージも高くなる。高くなる量は、効果値のクリティカルダメージの欄の値である。40である。シートの値に足す。100で会心係数が1増える。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| クリティカル率 | 35 |
| クリティカルダメージ | 40 |
