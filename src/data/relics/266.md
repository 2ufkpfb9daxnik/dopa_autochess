# 解説

- ID: 266
- 名前: 解説
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

与えたダメージの一部が体力に戻る。体力が低いと一度シールドになる。

## 詳細な説明文

このレリックを装備しているキャラクターが与えたダメージのうち、20%が体力に戻る。吸血は20である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。さらに、いまの体力が最大体力の、40%以下になったとき、1回だけシールドを得る。閾値は40である。シールドは最大体力のうち30%である。1戦闘に1回である。戦闘が終わるとシールドは消える。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 吸血 | 20 |
| 閾値 | 40 |
| シールド | 30 |
