# 連中

- ID: 267
- 名前: 連中
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

戦闘中、時間が経つほど速度が高くなる。戦闘が終わると戻る。

## 詳細な説明文

このレリックを装備しているキャラクターは、戦闘中、一定時間ごとに速度が高くなる。1回で増える量は、効果値の速度の欄の値である。8である。この欄は%ではない。間隔は、効果値の間隔の欄の値である。1である。秒である。戦闘が終わると、この上昇はすべて消える。外しても消える。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 速度 | 8 |
| 間隔 | 1 |
