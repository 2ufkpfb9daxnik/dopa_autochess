# セクション

- ID: 268
- 名前: セクション
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

攻撃するたび、または攻撃を受けるたび、その戦闘中の与ダメージが3%高くなる。

## 詳細な説明文

このレリックを装備しているキャラクターが通常の攻撃をしたとき、または攻撃でダメージを受けたとき、その戦闘中の与ダメージの積みが増える。1回で増える割合は3%である。上限は30である。上限に達したあと、さらに受けるダメージが10%だけ低くなる。10である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。戦闘が終わると消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 3 |
| 上限 | 30 |
| 軽減 | 10 |
