# 接着剤

- ID: 269
- 名前: 接着剤
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

最大体力が大きく高く、戦闘中に最大体力の一部が戻る。

## 詳細な説明文

このレリックを装備しているキャラクターの最大体力が35%高くなる。いまの体力も、増えた最大体力と同じだけ増える。戦闘中、一定時間ごとに体力が戻る。戻る量は最大体力のうち3%である。間隔は2である。秒である。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 最大体力 | 35 |
| 回復 | 3 |
| 間隔 | 2 |
