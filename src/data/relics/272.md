# 近影

- ID: 272
- 名前: 近影
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

戦闘中、一定時間ごとに与ダメージが20%高くなる。戦闘が終わると戻る。

## 詳細な説明文

このレリックを装備しているキャラクターは、戦闘開始時から、一定時間ごとに与ダメージが高くなる。1回で増える割合は20%である。間隔は5である。秒である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。戦闘が終わると消える。上限はない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 20 |
| 間隔 | 5 |
