# カメオ

- ID: 274
- 名前: カメオ
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

最大体力が高い敵への与ダメージが高い。

## 詳細な説明文

このレリックを装備しているキャラクターが、自分より最大体力が高い敵に与えるダメージが高くなる。高くなる割合は、効果値の与ダメージの欄の値である。30である。この欄は%である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。最大体力が自分以下の敵には入らない。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 30 |
