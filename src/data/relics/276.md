# 部屋

- ID: 276
- 名前: 部屋
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

装備者の近くの敵が受けるダメージが高い。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、その左右の隣にいる敵が受けるダメージが高くなる。高くなる割合は、効果値の受けるダメージの欄の値である。20である。この欄は%である。攻撃のダメージ、その範囲ダメージ、継続ダメージに入る。装備者の体力が0以下のときと、外したときに消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受けるダメージ | 20 |
