# 完結

- ID: 277
- 名前: 完結
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

一度だけ、倒されそうになっても耐え、しばらく狙われなくなる。

## 詳細な説明文

このレリックを装備しているキャラクターが、受けたダメージで体力が0以下になるとき、1戦闘に1回だけ、体力が1残る。そのあと、効果値の時間の欄の値のあいだ、敵の攻撃の対象にならない。時間は3である。この欄は%ではない。秒である。そのあいだも、範囲ダメージや継続ダメージではダメージを受ける。1戦闘に1回である。戦闘が終わると回数は戻る。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 時間 | 3 |
