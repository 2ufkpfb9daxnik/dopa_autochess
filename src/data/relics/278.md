# 執念

- ID: 278
- 名前: 執念
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

戦闘開始から、装備者の行動ポイントが合計1200減るまで、デバフを受けない。

## 詳細な説明文

このレリックを装備しているキャラクターは、戦闘開始から、そのキャラクターの行動ポイントが合計で1200減るまで、敵が付けるデバフを受けない。減る量は1200である。すでに付いているデバフは消えない。合計が1200に達したあとは通常どおりである。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 行動ポイント | 1200 |
