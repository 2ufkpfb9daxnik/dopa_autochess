# 遊牧

- ID: 279
- 名前: 遊牧
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

ラウンドごとに、与ダメージか回復かが切り替わる。

## 詳細な説明文

このレリックを装備しているキャラクターは、ラウンド開始時に効果側が切り替わる。与ダメージのラウンドでは、与ダメージが25%だけ高い。25である。回復のラウンドでは、通常の攻撃が命中したとき、最大体力のうち、12%が戻る。12である。入手した直後のラウンドは与ダメージ側である。外しても消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 25 |
| 回復 | 12 |
