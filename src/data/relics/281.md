# スペード

- ID: 281
- 名前: スペード
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

隣の味方の与ダメージが高い。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、その左右の隣にいる味方の与ダメージが高くなる。高くなる割合は、効果値の与ダメージの欄の値である。20である。この欄は%である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。装備者自身には入らない。装備者の体力が0以下のときと、外したときに消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 20 |
