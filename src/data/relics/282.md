# 到着

- ID: 282
- 名前: 到着
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

戦闘開始時、隣の味方にシールドを付ける。

## 詳細な説明文

このレリックを装備しているキャラクターがサークルにいるとき、戦闘開始時に、その左右の隣にいる味方にシールドを付ける。量は、その味方の最大体力のうち30%である。装備者自身には付かない。隣がいないときは何もしない。シールドは戦闘が終わると消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| シールド | 30 |
