# 海

- ID: 284
- 名前: 海
- 分類: 合成装備レベルの強さ
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

近くの敵に、時間とともに炎のダメージを与える。

## 詳細な説明文

このレリックを装備しているキャラクターの体力が0より大きいあいだ、一定時間ごとに、左右の隣にいる敵すべてに炎の攻撃を1回する。間隔は2である。秒である。攻撃力は装備者の攻撃力である。与ダメージは40%だけ低い。40である。隣がいないときは出ない。装備者の体力が0以下のときと、外したときに消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 間隔 | 2 |
| 与ダメージ | 40 |
