# 代用

- ID: 285
- 名前: 代用
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

入手時と、続く数ラウンドの開始時に、レリックが入る。入ったら消える。

## 詳細な説明文

このレリックを入手したとき、レリックが1つ、無作為に手元に入る。そのあと、ラウンド開始時にもレリックが1つ、無作為に手元に入る。ラウンド開始での入手は5までである。5回入ったら、このレリックは消える。入手時の1つは、この5回に数えない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ラウンド | 5 |
