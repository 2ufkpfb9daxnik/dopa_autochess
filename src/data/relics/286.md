# 水族館

- ID: 286
- 名前: 水族館
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方が倒れるたび進む。一定数でレリックが入る。回数上限あり。

## 詳細な説明文

このレリックを持っているあいだ、味方キャラクターが倒れるたびに進捗が1増える。進捗が、効果値の進捗の欄の値に達するたび、レリックが1つ無作為に手元に入り、進捗は0に戻る。進捗は15である。この欄は%ではない。レリックが入るのは、効果値の上限の欄の値の回数までである。3である。3回入ったら、このレリックは消える。召喚物やコピーや装置の破壊では増えない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 進捗 | 15 |
| 上限 | 3 |
