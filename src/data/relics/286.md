# 水族館

- ID: 286
- 名前: 水族館
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方が倒れるたびに進捗が1増える。15に達するたびレリックが1つ入る。3回まで。

## 詳細な説明文

このレリックを持っているあいだ、味方キャラクターが倒れるたびに進捗が1増える。進捗が15に達するたび、レリックが1つランダムに手元に入り、進捗は0に戻る。レリックが入るのは3回までである。3回入ったら、このレリックは消える。召喚物やコピーや装置の破壊では進捗は増えない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 進捗 | 15 |
| 上限 | 3 |
