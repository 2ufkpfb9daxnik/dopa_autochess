# 逆流

- ID: 287
- 名前: 逆流
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方が与えたダメージが一定に達したら、火力寄りの合成装備級レリックが2つ入る。

## 詳細な説明文

このレリックを持っているあいだ、味方キャラクターが与えたダメージの合計を覚える。合計が、戦闘開始時の味方全員の最大体力の合計に、8を掛けた数以上になったとき、報酬が入る。倍率は8である。報酬は、分類が合成装備レベルの強さのレリックのうち、与ダメージ・貫通・クリティカルに関係するものから、無作為に2つである。入ったあと、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 倍率 | 8 |
