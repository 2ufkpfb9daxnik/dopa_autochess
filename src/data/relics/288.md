# ジャングル

- ID: 288
- 名前: ジャングル
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方が受けたダメージが一定に達したら、耐久のレリックが2つ入る。

## 詳細な説明文

このレリックを持っているあいだ、味方キャラクターが受けたダメージの合計を覚える。合計が、戦闘開始時の味方全員の最大体力の合計に、効果値の倍率の欄の値を掛けた数以上になったとき、報酬が入る。倍率は8である。この欄は%ではない。報酬は、分類が「(プレイヤーもキャラクターも)HP、防御の増強、回復」のレリックから、無作為に2つである。入ったあと、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 倍率 | 8 |
