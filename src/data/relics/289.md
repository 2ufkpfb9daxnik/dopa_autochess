# ティラミス

- ID: 289
- 名前: ティラミス
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

クリティカルが一定回出たら、クリティカルを上げるレリックが2つ入る。

## 詳細な説明文

このレリックを持っているあいだ、味方キャラクターの攻撃がクリティカルになるたびに進捗が1増える。進捗が80に達したとき、報酬が入る。進捗は80である。報酬は、クリティカル率またはクリティカルダメージを高くするレリックから、無作為に2つである。入ったあと、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 進捗 | 80 |
