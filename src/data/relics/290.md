# 案内

- ID: 290
- 名前: 案内
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

通常の攻撃が一定回命中したら、速度を上げるレリックが2つ入る。

## 詳細な説明文

このレリックを持っているあいだ、味方キャラクターの通常の攻撃が命中するたびに進捗が1増える。進捗が、効果値の進捗の欄の値に達したとき、報酬が入る。進捗は200である。この欄は%ではない。報酬は、速度を高くするレリックから、無作為に2つである。外れでは増えない。入ったあと、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 進捗 | 200 |
