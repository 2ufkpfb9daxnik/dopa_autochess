# 金魚

- ID: 291
- 名前: 金魚
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

ゲージを一定量使ったら、ゲージを増やすレリックが2つ入る。

## 詳細な説明文

このレリックを持っているあいだ、味方キャラクターがゲージを減らして効果を出したときの、減った量の合計を覚える。合計が500以上になったとき、報酬が入る。ゲージは500である。報酬は、ゲージが増える量を高くするレリック、または攻撃でゲージが増えるレリックから、無作為に2つである。入ったあと、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゲージ | 500 |
