# 批評

- ID: 292
- 名前: 批評
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

同種合成を一定回したら、宇宙船またはエイリアンが入る。

## 詳細な説明文

このレリックを持っているあいだ、同種合成するたびに進捗が1増える。進捗が、効果値の進捗の欄の値に達したとき、宇宙船またはエイリアンのどちらかが1つ、無作為に手元に入る。進捗は5である。この欄は%ではない。異種合成では増えない。入ったあと、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 進捗 | 5 |
