# 司令塔

- ID: 296
- 名前: 司令塔
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

連勝が一定に達したら、ゴールドと無料更新が入る。

## 詳細な説明文

このレリックを持っているあいだ、連勝が、効果値の連勝の欄の値以上になったとき、報酬が入る。連勝は5である。この欄は%ではない。ゴールドが、効果値のゴールドの欄の値だけ入り、無料更新を、効果値の無料更新の欄の値だけ獲得する。ゴールドは15である。無料更新は5である。入ったあと、このレリックは消える。すでに連勝が5以上の状態で入手したときは、入手したときに入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 連勝 | 5 |
| ゴールド | 15 |
| 無料更新 | 5 |
