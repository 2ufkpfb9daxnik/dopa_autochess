# メトリック

- ID: 299
- 名前: メトリック
- 分類: クエスト・達成報酬
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

同種合成で★3にしたらゴールドが入る。回数上限あり。

## 詳細な説明文

このレリックを持っているあいだ、同種合成の結果の星が★3になったとき、ゴールドが入る。入る量は、効果値のゴールドの欄の値である。20である。この欄は%ではない。入るたびに残り回数を1減らす。残り回数の最初は、効果値の回数の欄の値である。2である。異種合成では入らない。★4にしたときは入らない。残り回数が0になると、このレリックは消える。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 20 |
| 回数 | 2 |
