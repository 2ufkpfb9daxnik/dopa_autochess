# クロージャ

- ID: 302
- 名前: クロージャ
- 分類: 複数レリック間の相互作用
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

味方の与ダメージが極度に高く、受けるダメージが極度に低い。毎ラウンド大きく得をする。

## 詳細な説明文

このレリックは、階段1と階段2と階段3をすべて持っているときだけ手元に入る。ショップやクエスト報酬など、無作為にレリックを選ぶ処理には出ない。一度入ったら残る。階段をあとから失っても消えない。このレリックを持っているあいだ、味方全員の与ダメージが高くなる。高くなる割合は、効果値の与ダメージの欄の値である。300である。この欄は%である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。味方全員が攻撃で受けるダメージが低くなる。低くなる割合は、効果値の受けるダメージの欄の値である。70である。継続ダメージにも入る。ラウンド開始時に、ゴールドが、効果値のゴールドの欄の値だけ入る。20である。経験値が、効果値の経験値の欄の値だけ入る。8である。無料更新を、効果値の無料更新の欄の値だけ獲得する。3である。この欄は%ではない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 300 |
| 受けるダメージ | 70 |
| ゴールド | 20 |
| 経験値 | 8 |
| 無料更新 | 3 |
