# 民話

- ID: 304
- 名前: 民話
- 分類: 複数レリック間の相互作用
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

レリックを1つ消費すると、経験値が入る。

## 詳細な説明文

このレリックを持っているあいだ、手元のレリックを1つ選んで消すと、経験値が入る。入る量は、効果値の経験値の欄の値である。8である。この欄は%ではない。階段1、階段2、階段3、クロージャは、この消費の対象にできない。民話自身を消費の対象にしてもよい。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 経験値 | 8 |
