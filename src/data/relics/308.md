# 索引

- ID: 308
- 名前: 索引
- 分類: 複数レリック間の相互作用
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

ラウンド開始時、持っているレリックの数だけゴールドが入る。

## 詳細な説明文

このレリックを持っているあいだ、ラウンド開始時に、いま持っているレリックの個数だけゴールドが入る。1つあたり、効果値のゴールドの欄の値である。1である。この欄は%ではない。索引自身も数に入る。指南や幻想で追加で入ったレリックも数に入る。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 1 |
