# ハイブリッド

- ID: 311
- 名前: ハイブリッド
- 分類: 複数レリック間の相互作用
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

ほかのレリックの効果が、その戦闘で初めて発動したとき、ゴールドが入る。

## 詳細な説明文

このレリックを持っているあいだ、自分のほかのレリックの効果が、そのプレイヤー同士の戦闘で初めて発動したとき、ゴールドが入る。入る量は、効果値のゴールドの欄の値である。2である。この欄は%ではない。1回の戦闘で入る回数は、効果値の上限の欄の値までである。3である。ハイブリッド自身の効果では入らない。同じレリックの2回目以降の発動では入らない。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| ゴールド | 2 |
| 上限 | 3 |
