# 階段1

- ID: 312
- 名前: 階段1
- 分類: 複数レリック間の相互作用
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

与ダメージが高く、毎ラウンド無料更新を獲得する。

## 詳細な説明文

このレリックを持っているあいだ、味方全員の与ダメージが高くなる。高くなる割合は、効果値の与ダメージの欄の値である。15である。この欄は%である。通常の攻撃、その範囲ダメージ、継続ダメージに入る。ラウンド開始時に、無料更新を獲得する。獲得する数は、効果値の無料更新の欄の値である。1である。階段2と階段3とあわせて持っているとき、クロージャが手元に入る。クロージャの節である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 15 |
| 無料更新 | 1 |
