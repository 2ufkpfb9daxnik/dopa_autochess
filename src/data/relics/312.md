# 階段1

- ID: 312
- 名前: 階段1
- 分類: 複数レリック間の相互作用
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

与ダメージが高く、毎ラウンド無料更新が1回入手できる。

## 詳細な説明文

このレリックを持っているあいだ、味方全員の与ダメージが15%高くなる。通常の攻撃、その範囲ダメージ、継続ダメージに入る。ラウンド開始時に、無料更新が1回入手できる。階段2と階段3とあわせて持っているとき、クロージャが手元に入る。クロージャの節である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 与ダメージ | 15 |
| 無料更新 | 1 |
