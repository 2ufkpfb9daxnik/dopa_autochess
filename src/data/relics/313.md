# 階段2

- ID: 313
- 名前: 階段2
- 分類: 複数レリック間の相互作用
- 装備可能: はい
- 合成可能: はい

## 簡単な説明文

受けるダメージが低く、毎ラウンドゴールドが入る。

## 詳細な説明文

このレリックを持っているあいだ、味方全員が攻撃で受けるダメージが低くなる。低くなる割合は、効果値の受けるダメージの欄の値である。10である。この欄は%である。継続ダメージにも入る。ラウンド開始時に、ゴールドが、効果値のゴールドの欄の値だけ入る。2である。この欄は%ではない。階段1と階段3とあわせて持っているとき、クロージャが手元に入る。クロージャの節である。

## 効果値

レリックが変える数値。単位は欄による。

| 効果値 | 値 |
| --- | ---: |
| 受けるダメージ | 10 |
| ゴールド | 2 |
